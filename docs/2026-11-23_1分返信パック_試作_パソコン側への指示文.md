（コードはリーダーが GitHub に保存（commit・push）してから使えます。）
所要時間の目安：オーナーが画面の前にいる時間 約30分（許可画面・LINEの合言葉の貼り付け・テスト送信の確認）。

「1分返信パック」（お客さま向けの自動化商品）のひな形を、**当社のGoogleアカウントで試しに動かす**作業です。Googleフォームに問い合わせが入ると、表に記録 → 問い合わせた人へ自動返信メール → 私のLINEに通知、が動くかを確かめます。次の順番で進めてください。

守ってほしいこと：
- お客さま・本番の仕組み（n8nのワークフロー、turtle-ad.com のフォーム、LINEの設定）には触らないでください。n8nは見るだけにしてください。
- LINEの合言葉（チャネルアクセストークン）は、私がスプレッドシートのセルに直接貼ります。チャットや作業記録には書かないでください。
- Googleの許可画面のボタンは私が押します。押す前に、どの画面か教えてください。

3. プログラムを貼る

   - コード.gs（Code.gs）の中身を、手順1の Code.gs の中身にすべて置き換えてください。
   - 保存（Ctrl+S）してください。プロジェクト名は「1分返信パック」にしてください。
   - スプレッドシートの画面に戻って再読み込み（F5）すると、上のメニューに「自動化」が出ます。
