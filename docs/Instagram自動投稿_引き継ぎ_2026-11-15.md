
### 切り分けで分かったこと（すべて試して失敗）
| 試したこと | 結果 |
|---|---|
| アカウントを変える（`my_town_job` で同じ動画） | 同じ2207085 |
| 動画の長さを変える（31秒→15秒） | 同じ2207085 |

| APIのバージョンをv26に指定 | v27に自動で切り替えられて同じ2207085 |
| 2分待ってから公開をやり直す | 同じ2207085 |

- Metaの返事には毎回 `x-ad-api-version-warning: The call has been auto-upgraded to v27.0 as v24.0 has been deprecated.` が付いていました。
- 投稿上限（`content_publishing_limit`）は 0/100 で、上限の問題ではありませんでした。

### 解決
- Meta for Developers のアプリ「**turtle ad 自動投稿**」（アプリID 2909226914710109、モード：開発中）で、ユースケース「Instagramでメッセージとコンテンツを管理」→「**API setup with Unified login（統合ログイン）**」の設定を新しく作りました（Create from template）。
- 3アカウント（my_town_job／my_town_guide／turtle_ad_pro）を選んでトークンを作り、n8nに登録しました。
- このトークンで、`graph.facebook.com/v27.0` に対して `my_town_job` にリールを公開し、**成功**しました（2026-11-15 07:32 UTC、メディアID 17976495128948255、15秒のテスト版）。
- 補足：「InstagramログインによるAPI設定」（graph.instagram.com）は、新しいアプリでは使えないと表示されました。

### 新しい認証情報の注意点
- n8nの認証情報「**Instagram統合ログイン**」（ID `23i8YVAAIGiSNVVX`、種類は Header Auth）
  - Name: `Authorization`
  - Value: `Bearer EAG…`（**`Bearer ` を付けないと「Authentication Error (190)」になります**）
- 窓口は **graph.facebook.com**（graph.instagram.com では無効と返されます）。
- 有効期限：設定画面では「無期限（システムユーザートークン）」と表示されていました（要確認）。
- 古い認証情報「Instagram自動投稿 (n8n-autopost)」（ID `m1SUWjkzjOewq75h`、facebookGraphApi）は、**最近の投稿を確認するノード（読み取り）でまだ使っています。削除しないでください。**
- トークンの中身は、チャットやファイルに書かないでください。

### 本番ワークフローの流れ（uMx9CiJMmRbnPEvg）
1. 30分ごとに予定表を読み、ガイドとジョブの最近の投稿を確認する（古い認証情報で読み取り）。
2. 「時間が来た1件を選ぶ」（Code）で、時刻が来た承認済み・承認待ちの予定を**1回に1件だけ**選ぶ。
   - 1日2本まで・3時間以上あける・同じ会社は30日あける（ストーリーズは対象外）。
   - 同じアカウント・同じ形式・同じfileIdがすでに投稿済みなら飛ばす。
   - 自動チェック（電話番号、VOICEVOXの表記、注意が必要な言葉など）に引っかかったら「要確認」にしてLINEで通知する。
3. 「投稿中」にする → 動画の一時URLを取る（fileIdが `http` で始まるならそのURLを使う）→ コンテナ作成（**新トークン**）→ 90秒待つ → 処理状況を確認（**新トークン**）
4. 公開する（**新トークン**、エラーでも止めない）→ 失敗したら2分待って1回やり直す → 成功なら「投稿済み」＋igMediaId、失敗なら「失敗」。
5. 失敗のときは、noteとLINEにエラーの全文（`code/subcode/trace`）が残る。

### 予定表（n8nデータ表「Instagram投稿予定表」ID `c7H4zVyagZxXvxnH`、プロジェクト `x38o23h5wCHsgCOg`）
主な列：postAt(UTC) / account / format(REELS・IMAGE・STORIES) / kind / company / fileId / fileName / caption / status / note / igMediaId

| status | 意味 |
|---|---|
| 承認済み・承認待ち | 時間が来たら自動で投稿される（**承認待ちも投稿される**ので注意） |
| 画像待ち | 投稿されない。noteに `[自動承認]` があれば、OneDriveで同じ名前の画像が見つかった時点で承認済みになる |
| 投稿中 | 投稿の途中。1時間以上たって igMediaId がなければ止まったもの（id2・id17が残っている） |
| 投稿済み・失敗・要確認・保留 | 自動では触らない |

- MCPのツールには、予定表の行を**書き換える機能がありません**（追加と読み取りだけ）。status を変えたいときは、n8nの画面で直接直すか、ワークフローを作ってください。
- 画像は**JPEGのみ**。縦横比は4:5〜1.91:1（APIは3:4を受け付けません）。
- fileId には、GitHubの公開URL（`https://raw.githubusercontent.com/sp734sn9boy-afk/turtlead-reels/<ブランチ>/...`）も使えます。OneDriveの一時URLは、動画の取り込みで2207077（アップロード失敗）になることがありました（建築屋ひかり・SARIX）。
