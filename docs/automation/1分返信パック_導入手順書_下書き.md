# 1分返信パック 導入手順書（下書き）

作成：2026-11-23 仕組み担当／状態：**下書き**（当社アカウントでの試作が終わったら、画面写真を入れて仕上げる）
使い方：当社の担当者が、お客さまと画面共有（Google Meet・Zoomなど）をしながら、この順番で進める。所要 **30〜45分**。

---

## 0. 事前にお客さまへ送る案内文（貼り付けて送る用）

> ○○様
> 「1分返信パック」の設定のお打ち合わせ（約45分）、ありがとうございます。当日は画面を共有しながら、一緒に設定します。
> 次の3つをご用意ください。
> 1. お店で使っているGoogleアカウントにログインできるパソコン（スマホでは設定できません）
> 2. LINE公式アカウントにログインできる状態（お持ちでなければ当日一緒に作ります。無料です）
> 3. 自動返信メールの文面の案（「〇営業日以内にご連絡します」など。当社のひな形からでも大丈夫です）
>
> ※途中でGoogleから「このアプリは確認されていません」という画面が出ます。お客さまご自身のアカウントの中で動く仕組みのために出る表示で、問題はありません。当日ご説明します。

### 当社が事前に決めておくこと
- 動かすGoogleアカウント：**スタッフ個人ではなく、お店のアカウント**（担当者が辞めても止まらないように）
- 受け口：Googleフォームを新しく作るか／今あるGoogleフォームを使うか／（オプション）Gmailに届く問い合わせメールも読むか
- 通知を受け取る人（LINE）：何人か、誰か
- 自動返信を送る時間帯（例：8時〜21時）
- AIの下書きを付けるか（付けるなら、お客さま名義でAnthropicのAPIキーが必要。手順7）

---

## 1. スプレッドシートをコピーする（3分）

1. 当社から送るコピー用リンク（`https://docs.google.com/spreadsheets/d/（ひな形のID）/copy`）を開く。
2. お店のGoogleアカウントでログインしているか、右上のアイコンで確認する。
3. 「コピーを作成」を押す。お客さまのGoogleドライブに「1分返信パック のコピー」ができる。名前を「1分返信パック（お店の名前）」に変える。

→ お客さまのドライブに入ったファイルは、**お客さまのもの**です。当社は中のデータを見られません（保守のために当社を「編集者」に追加するかは、手順9でお客さまに選んでいただく）。

## 2. Googleフォームをつなぐ（5分）

- 新しく作る場合：フォームに「お名前」「メールアドレス」「電話番号」「お問い合わせ内容」の質問を作る（質問名がこのとおりなら設定を変えずに使えます）。
- 今あるフォームを使う場合：質問名を「設定」シートの「フォーム項目（名前）」などに書き足す。
- フォームの「回答」タブ →「スプレッドシートにリンク」→「既存のスプレッドシートを選択」→ 手順1のファイルを選ぶ。

## 3. 「設定」シートを埋める（10分）

お客さまと一緒に、B列を入れる（C列に説明があります）。

| 項目 | 入れるもの |
|---|---|
| 店名 | お店の名前（自動返信メールの差出人名になります） |
| お客さま連絡先メール | 止まったときのお知らせを受け取る、お店のメール |
| 見守り先メール | 当社の見守り用アドレス（ひな形に入っています。そのまま） |
| 自動返信の件名・本文 | 文面。`{名前}` は問い合わせた人の名前、`{署名}` は下の署名に置き換わります。**問い合わせの内容は本文に入れません**（他人のアドレスを入れて迷惑メールを送らせるいたずらを防ぐため） |
| 署名 | 店名・電話番号・住所など |
| 返信先メール | 自動返信に「返信」されたときの宛先（空ならこのGoogleアカウント） |
| 送信する時間帯 | 例：開始 8・終了 21。時間外の問い合わせは記録だけして、朝8時に送ります |
| 1日の上限 | メール 80（無料のGoogleアカウントは1日100通まで）、LINE 50 |
| LINE通知先ユーザーID・トークン | 手順4で入れます |

## 4. LINEの準備（10〜15分）

1. LINE公式アカウントが無ければ作る（無料のコミュニケーションプランでOK。担当者への通知だけなら月200通の無料枠に収まることが多い）。
2. LINE公式アカウントの管理画面 →「設定」→「Messaging API」→「Messaging APIを利用する」。初めてなら開発者情報を登録し、プロバイダーを作る（名前はお店の名前）。
3. LINE Developers（https://developers.line.biz/console/ ）→ 作られたチャネル →「Messaging API設定」→「チャネルアクセストークン（長期）」の「発行」を押す → 出てきた文字をコピーして、「設定」シートの「LINEチャネルアクセストークン」に**お客さまご自身で貼る**（当社はチャットなどで受け取りません）。
   - 貼った文字は、次に動いたときに隠し設定に移り、セルは「（保存済み・表示しません）」に変わります。
   - すでに他のLINEツールでトークンを使っている場合、「再発行」は押さない（他のツールが止まるため）。
4. 通知を受け取る人が、そのLINE公式アカウントを友だち追加する。
5. 店主の方のユーザーID：LINE Developers のチャネル「チャネル基本設定」の一番下「あなたのユーザーID」（U から始まる33文字）をコピーして、「LINE通知先ユーザーID」に貼る。スタッフの分は当社で調べ方をご案内します（複数はカンマで区切る）。

## 5. 初期設定と許可の画面（5分）— **必ずお客さまご本人が押す**

スプレッドシートを再読み込みすると、上に「自動化」メニューが出ます。「自動化」→「① 初期設定（最初に1回）」を押します。

**ここで出る画面（お客さまへの説明つき）**

1. 「承認が必要です」→「OK」
2. Googleアカウントを選ぶ → **お店のアカウント**を選ぶ
3. **「このアプリは Google で確認されていません」**
   - 説明：「Googleが審査していない仕組みに、アカウントの中を使わせるときに出る決まった表示です。今回の仕組みは、さきほどコピーした、お客さまご自身のファイルの中で動くもので、外の会社のアプリではありません。当社がお客さまのメールを読んだり、送ったりすることもありません。」
   - 操作：左下の「詳細」→「1分返信パック（安全ではないページ）に移動」
   - 会社のGoogle Workspaceで、ファイルの持ち主と使う人が同じ会社なら、この画面は出ません。
4. 「1分返信パック が Google アカウントへのアクセスを求めています」
   - 項目ごとにチェックが出たら、**「すべて選択」にチェック**して「続行」。一部を外すと、その機能（例：メール送信）が動きません。
   - 説明：「メールを送る・フォームの回答を読む・LINEに知らせる・時間になったら動く、のために必要な許可です。」
5. 「初期設定が終わりました」「このGoogleアカウントで動きます：（お店のアドレス）」と出れば完了。**アドレスがお店のものか、必ず一緒に確認する。**

※当社の担当者が画面を操作して押すと、当社のアカウントで動いてしまいます。この手順だけは必ずお客さまに押していただく。

## 6. テスト（5分）

1. 「自動化」→「② テスト送信」→ 結果に「自動返信：済」「LINE通知：済」と出る。
2. お客さま連絡先メールに自動返信が届いたか、LINEに通知が届いたかを一緒に確認する。
3. フォームのプレビューから1件送ってみて、1分以内に記録・メール・LINEがそろうか確認する。
4. 「受付記録」シートの見方を説明する（「対応状況」の列は、お店の方が「対応済み」などと書き込んで使う）。

## 7. （オプション）AIの返信下書き（10分）

1. お客さま名義でAnthropicのアカウントを作る（https://platform.claude.com/ ）→ クレジットカード登録 → 少額のクレジットを購入 → 使いすぎ防止の月の上限を設定。
2. APIキーを作り、「設定」シートの「AIのAPIキー」にお客さまご自身で貼る（隠し設定に移ります）。
3. 「AI下書き」を「する」、「AIへの説明（お店の情報）」に営業時間・料金・よくある質問を書く。**ここに無いことはAIは約束しない作り**です。
4. テスト送信で、Gmailの「下書き」に返信案ができるか確認。**送る前に必ず人が読んで直す**ことをお伝えする。
- 費用の目安：問い合わせ1件あたり1円未満（Claude Haiku 5.5）。

## 8. （オプション）Gmailに届く問い合わせメールも読む

- 「Gmailの問い合わせも読む」を「する」、「Gmailの検索条件」に問い合わせメールの見分け方（例：`from:wordpress@お店のドメイン subject:お問い合わせ newer_than:3d`）を入れる。
- メールで届いた問い合わせへの自動返信は、迷惑メールにも返信してしまうおそれがあるため、初期値は「しない」。

## 9. 最後に確認すること（3分）

- [ ] 「このGoogleアカウントで動きます」がお店のアカウントだった
- [ ] テスト送信の自動返信とLINEが届いた
- [ ] 当社を「編集者」に追加するか（追加すると、不具合のときに当社が直せます。追加しない場合は、直すときにまた画面共有をお願いします）
- [ ] 止めたいときは「自動化」→「自動化を止める」で止まることをお伝えした
- [ ] 月額の見守りの内容（週1回の動作確認、止まったときの対応、文面の変更）をお伝えした

## 10. 困ったとき（お客さま向けの短い説明）

| こんなとき | どうする |
|---|---|
| 「[要確認] 1分返信パック」というメールが来た | 当社にも同じメールが届いています。当社から連絡します（急ぎならLINEでご連絡ください） |
| 自動返信が届かないと言われた | 「受付記録」の「自動返信」の列を見る。「スキップ（同じ宛先に送信済み）」は24時間以内の2通目、空なら時間外か上限で保留中 |
| LINEが来ない | LINE公式アカウントをブロックしていないか、無料枠（月200通）を超えていないか |
| 担当者が変わる・アカウントを変える | 当社に連絡（新しいアカウントで「① 初期設定」をやり直す必要があります） |
