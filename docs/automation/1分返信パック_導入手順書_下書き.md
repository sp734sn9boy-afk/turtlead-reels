## 1. スプレッドシートをコピーする（3分）

## 3-2. （希望があれば）自動返信の送り主を info@ にする（10〜20分）

**まず確認：お客さまのメールはどこにありますか？**

| お客さまの状況 | どうするか |
|---|---|
| **Google Workspace**（会社のドメインでGmailを使っている） | 外部のメールサーバーの登録は**不要**。管理者が info@ を「別名」または「グループ」として作り、Gmailの「設定」→「アカウント」→「名前」の「他のメールアドレスを追加」で info@ を追加（Googleのアドレスなので、メールサーバーの入力は出ない）。今後も使い続けられる |
| **無料のGmail ＋ 外部のメール**（ロリポップ・エックスサーバー等の info@） | 下の方法で登録できるが、**Googleは「外部のアドレスから送信」を2027年1月に終了予定**と案内しており、新しい登録はすでに制限されることがある。**おすすめは「送り主はGmailのまま、返信先メールに info@ を入れる」形**（お客さまが返信すると info@ に届く） |

出典：Gmailのサポート終了のお知らせ https://support.google.com/mail/answer/16604719 ／別のアドレスから送信 https://support.google.com/mail/answer/22370 （作業環境から直接開けなかったため検索結果で確認。導入前に最新の内容を確認する）

### 無料のGmailで外部の info@ を送信元に登録する手順（2027年1月まで・登録できた場合のみ）
1. パソコンのGmail → 右上の歯車 →「すべての設定を表示」→「アカウントとインポート」タブ。
2. 「名前」の「他のメールアドレスを追加」→ 名前（店名）と info@… を入れ、「エイリアスとして扱います」はチェックのまま →「次のステップ」。
3. メールサーバーの情報を入れる。**値は契約しているサーバー会社ごとに違う**ので、「（会社名） メールソフト 設定 SMTP」で検索し、会社の公式マニュアルの「送信メールサーバー（SMTP）」の値を写す。
   - SMTPサーバー：マニュアルの「送信サーバー」（例の形：smtp.○○.jp）
   - ポート：マニュアルの指定（多くは 465＝SSL、または 587＝TLS）
   - ユーザー名：多くはメールアドレス全体（info@…）
   - パスワード：そのメールアドレスのパスワード（お客さまご本人が入れる）
4. 「アカウントを追加」→ info@ に確認のメールが届く → 中のリンクを押す（または確認コードを入れる）。
5. 「設定」シートの「送り主アドレス」に info@… を入れて、「自動化」→「① 初期設定」をもう一度押す。登録されていなければ「送信元に登録されていません」と出て止まる。
6. 「② テスト送信」で、届いたメールの差出人が info@ になっているか確認。

**登録が外れたとき（2027年1月の終了など）の動き**：自動返信はGmailのアドレスで勝手に送らず、**保留して、当社とお客さまに1日1回お知らせ**する（LINE通知と記録は続く）。「送り主アドレス」を空にして「返信先メール」に info@ を入れれば、保留分（受付から48時間以内のもの）が送られる。
→ Gmailのまま送らない理由：お客さまがお店の個人用Gmailアドレスを出したくない場合があり、黙って送り主が変わると「なりすまし」に見えて問い合わせた人を不安にさせるため。

### info@ に届くメールをGmailで読む（転送の設定）
- 外部のメールサーバーの管理画面で、info@ に届いたメールを店のGmailへ**転送**する設定をする（Gmailの「他のアカウントのメールを確認（POP）」はGoogleが2027年1月に終了予定のため、転送を使う）。
- ロリポップの例：ロリポップの「ユーザー専用ページ」→「メール」→ 対象のアドレスの設定 →「転送」を有効にし、転送先にGmailのアドレスを入れる（「転送したメールをサーバーに残す」はお好みで）。※画面の名前は変わることがあるので、ロリポップのマニュアルで「メール 転送」を確認する。
- 他の会社も、たいてい管理画面の「メール」→「転送設定」にある。

### 迷惑メール扱いを避けるために（一言）
- 送り主のドメイン（例：お店のドメイン）に **SPF**（送ってよいサーバーの一覧）が設定されている必要がある。サーバー会社のSMTPで送る場合は、たいてい会社が最初から設定している。**DKIM・DMARC** も設定できるならしておくと、GmailやYahooで迷惑メールに入りにくい。
- 確認方法：テスト送信をGmailで受け取る → メールを開いて右上の「︙」→「メッセージのソースを表示」→ SPF・DKIM・DMARC が「PASS」になっているか見る。FAILなら、サーバー会社のマニュアルの「SPF」「DKIM」の設定をする（DNSの設定。分からなければ当社で代行）。

## 4. LINEの準備（10〜15分）

1. LINE公式アカウントが無ければ作る（無料のコミュニケーションプランでOK。担当者への通知だけなら月200通の無料枠に収まることが多い）。
2. LINE公式アカウントの管理画面 →「設定」→「Messaging API」→「Messaging APIを利用する」。初めてなら開発者情報を登録し、プロバイダーを作る（名前はお店の名前）。
3. LINE Developers（https://developers.line.biz/console/ ）→ 作られたチャネル →「Messaging API設定」→「チャネルアクセストークン（長期）」の「発行」を押す → 出てきた文字をコピーして、「設定」シートの「LINEチャネルアクセストークン」に**お客さまご自身で貼る**（当社はチャットなどで受け取りません）。
   - 貼った文字は、次に動いたときに隠し設定に移り、セルは「（保存済み・表示しません）」に変わります。
   - すでに他のLINEツールでトークンを使っている場合、「再発行」は押さない（他のツールが止まるため）。
4. 通知を受け取る人が、そのLINE公式アカウントを友だち追加する。
5. 店主の方のユーザーID：LINE Developers のチャネル「チャネル基本設定」の一番下「あなたのユーザーID」（U から始まる33文字）をコピーして、「LINE通知先ID」に貼る。スタッフ個人やグループのIDは、手順4-2の「LINEのID調べ」で調べる（複数はカンマで区切る。個人とグループの混在OK）。

## 4-2. （希望があれば）スタッフのLINEグループに通知する（15〜20分）

※この手順は、手順5（初期設定）が終わってから行う（設定シートとLINEの合言葉が必要なため）。

**先にお伝えすること（通数）**
- LINEのPush送信（こちらから送るメッセージ）は、**グループに送ると、グループの人数分が通数に数えられます**。例：5人のグループに通知1回＝5通。無料プランは月200通まで（上限を超えると送れない）なので、5人のグループなら**月40件の問い合わせ**で無料枠を使い切ります。
- 出典：LINE Developers「メッセージを送信する」（送信数は送った相手の人数で数える）https://developers.line.biz/en/docs/messaging-api/sending-messages ／「Messaging APIの通数カウント方法」https://developers.line.biz/ja/tips/2026/05/28/how-to-count-messages/ ／料金 https://developers.line.biz/ja/docs/messaging-api/pricing/ 
- この仕組みは、グループの人数をLINEに問い合わせて、人数分で「1日の上限（LINE）」を数えます。問い合わせが多いお店は、個人あて（担当者1〜2人）にするか、LINEの有料プラン（ライト：月5,000円・5,000通）を検討。

**グループIDの調べ方**（LINEのアプリの画面ではグループIDが見えないため、この仕組みの「LINEのID調べ」を一時的に使う）
1. LINE公式アカウントの管理画面 →「設定」→「アカウント設定」→「機能の利用」の「グループ・複数人チャットへの参加」を「許可する」。
2. 「設定」シートの「LINEのID調べ（受け口）」を「する」にする。
3. Apps Script の画面（スプレッドシートの「拡張機能」→「Apps Script」）→ 右上の「デプロイ」→「新しいデプロイ」→ 種類の歯車で「ウェブアプリ」→ 次のユーザーとして実行「自分」、アクセスできるユーザー「全員」→「デプロイ」。許可の画面が出たら手順5と同じように進める（「詳細」→「安全ではないページに移動」→「すべて選択」→「続行」）。出てきた「ウェブアプリのURL」（…/exec で終わる）をコピー。
4. LINE Developers → チャネル →「Messaging API設定」→「Webhook URL」の「編集」→ 3のURLを貼って「更新」→「Webhookの利用」をオンにする。
   - **すでに別のツール（Lステップ等）のURLが入っていたら、元のURLを控えておき、調べ終わったら必ず元に戻す**（そのままだと、そのツールが止まります）。
   - 「検証」ボタンはエラーになることがあります（Googleのウェブアプリの仕組みのため）。気にせず次へ。【当社の試作で確認予定】
   - LINE公式アカウントの管理画面の「応答設定」で「Webhook」がオンになっているかも確認。
5. LINEのアプリで、スタッフのグループにLINE公式アカウントを招待する。グループに「このグループを通知先の候補として記録しました。グループのID：C…」と返事が来る（返事は通数に数えられません）。
   - すでにグループに入っている場合は、グループで「ID」とだけ送ると、同じ返事が来ます。スタッフ個人のIDも、公式アカウントとの1対1のトークで「ID」と送れば分かります。
6. スプレッドシートの「LINEのID調べ」シートにも記録されるので、そのIDを「設定」の「LINE通知先ID」に貼る（カンマで区切って追加）。
7. **後片付け（必ず）**：「LINEのID調べ（受け口）」を「しない」に戻す → Apps Script の「デプロイ」→「デプロイを管理」→ そのデプロイを「アーカイブ」→ LINE Developers の Webhook URL を空に（または元のURLに）戻す。
   - 理由：Googleのウェブアプリでは、届いた知らせが本当にLINEからのものかを確かめられないため。この仕組みは受け取ったIDを記録するだけで、通知先には自動で入れません（人が確かめて貼る）。
8. 「② テスト送信」で、グループに通知が届くか確認。

## 5. 初期設定と許可の画面（5分）— **必ずお客さまご本人が押す**

スプレッドシートを再読み込みすると、上に「自動化」メニューが出ます。「自動化」→「① 初期設定（最初に1回）」を押します。

**ここで出る画面（お客さまへの説明つき）**

1. 「承認が必要です」→「OK」
2. Googleアカウントを選ぶ → **お店のアカウント**を選ぶ
3. **「このアプリは Google で確認されていません」**
   - 説明：「Googleが審査していない仕組みに、アカウントの中を使わせるときに出る決まった表示です。今回の仕組みは、さきほどコピーした、お客さまご自身のファイルの中で動くもので、外の会社のアプリではありません。当社がお客さまのメールを読んだり、送ったりすることもありません。」
   - 操作：左下の「詳細」→「1分返信パック（安全ではないページ）に移動」
   - 会社のGoogle Workspaceで、ファイルの持ち主と使う人が同じ会社なら、この画面は出ません。
4. 「1分返信パック が Google アカウントへのアクセスを求めています」
   - 項目ごとにチェックが出たら、**「すべて選択」にチェック**して「続行」。一部を外すと、その機能（例：メール送信）が動きません。
   - 説明：「メールを送る・フォームの回答を読む・LINEに知らせる・時間になったら動く、のために必要な許可です。」
5. 「初期設定が終わりました」「このGoogleアカウントで動きます：（お店のアドレス）」と出れば完了。**アドレスがお店のものか、必ず一緒に確認する。**

※当社の担当者が画面を操作して押すと、当社のアカウントで動いてしまいます。この手順だけは必ずお客さまに押していただく。

## 7. （オプション）AIの返信下書き（10分）

1. お客さま名義でAnthropicのアカウントを作る（https://platform.claude.com/ ）→ クレジットカード登録 → 少額のクレジットを購入 → 使いすぎ防止の月の上限を設定。
2. APIキーを作り、「設定」シートの「AIのAPIキー」にお客さまご自身で貼る（隠し設定に移ります）。
3. 「AI下書き」を「する」、「AIへの説明（お店の情報）」に営業時間・料金・よくある質問を書く。**ここに無いことはAIは約束しない作り**です。
4. テスト送信で、Gmailの「下書き」に返信案ができるか確認。**送る前に必ず人が読んで直す**ことをお伝えする。
- 費用の目安：問い合わせ1件あたり1円未満（Claude Haiku 5.5）。

## 8. （オプション）Gmailに届く問い合わせメールも読む

- 「Gmailの問い合わせも読む」を「する」、「Gmailの検索条件」に問い合わせメールの見分け方（例：`from:wordpress@お店のドメイン subject:お問い合わせ newer_than:3d`）を入れる。
- メールで届いた問い合わせへの自動返信は、迷惑メールにも返信してしまうおそれがあるため、初期値は「しない」。

## 10. 困ったとき（お客さま向けの短い説明）

| こんなとき | どうする |
|---|---|
| 「[要確認] 1分返信パック」というメールが来た | 当社にも同じメールが届いています。当社から連絡します（急ぎならLINEでご連絡ください） |
