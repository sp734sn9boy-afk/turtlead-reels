# ココナラ画像パターン集（デザイン担当の覚え書き）

作成：2026-11-21　デザイン担当
目的：ココナラのサービス画像を作るたびにここを開き、「毎回同じ型」にならないようにする。

## 0. この調査のやり方と限界

- 見たもの：ココナラの公開検索結果（ログインなし）。検索語は「リール動画 作成」「AI動画」「ショート動画」「ロゴ アニメーション」「ホームページ制作」「WordPress 保守」「ChatGPT 教えます」「生成AI 研修」の8つ。おすすめ順・ランキング順・新着順を取得。
- じっくり見たサムネ：重複をのぞいて216件（評価件数の多い上位146件＋ランキング上位23件＋新着で評価0件の47件）。個別ページの2枚目以降は6出品ぶん。
- 他社の画像はリポジトリに保存していない（一覧スクショはスクラッチパッドのみ）。この文書にも出品名・画像は載せない。
- 限界（正直に）：
  - ココナラのキーワード検索はゆるく、上位には隣のジャンル（資料作成・イラスト・音楽など）も混ざる。
  - 「評価が多い＝画像が良いから」とは言い切れない。評価2,000件超でも白地に文字だけの画像があった。すでに実績がある人は画像が弱くても売れる。**画像が効くのは、うちのような評価0件の新規出品のとき**。
  - 売上や購入率そのものは見えない。見えるのは評価件数・ランキング順位だけ。

## 1. 画像の決まりごと（サイズと切れ方）

- 元画像は 1220×1240px（ほぼ正方形）。
- 検索一覧では横長（約 1.21:1）に切り取られて表示される。**上下それぞれ約115pxは一覧で見えなくなる**と考えて、見出し・価格・作品は縦の中央 約1000px に収める。
- パソコンの一覧では横180px前後、スマホではさらに小さい。**180pxに縮めて読めない文字は「無い」のと同じ**。作ったら必ず180px幅に縮めて確認する。
- 新着の評価0件には、文字が左右で切れている画像がいくつもあった（横長の画像をそのまま使ったため）。これは一番もったいない失敗。

## 2. パターン一覧（実際に見たものから分類）

「よく見る度」は上位146件の中での体感。★3つ＝とても多い。

### P1. 実績数字バッジ型　★★★
- 見た目：月桂冠・リボン・丸バッジの中に「販売〇〇件」「評価5.0」「部門1位」。数字だけ色を変えて特大。
- 多いカテゴリ：全部。特にHP制作・資料作成・動画編集。
- 売れている出品での使用：上位のおよそ3〜4割に何かしらの数字バッジが入る。
- 色：金・赤・紺。白地に金バッジ、または黒地に金。
- 文字：数字は画像の高さの1/5以上。説明は少なめ。
- うちで使えるか：**今は使えない（評価0件）。うその数字は絶対に入れない**。代わりに「約束の数字」（15秒、写真5枚、9,800円、66,000円、60分）を同じ見せ方で使う。評価がたまったら切り替える。

### P2. 太文字ポスター型（サービス名ドーン）　★★★
- 見た目：「動画編集」など4〜6文字を画面いっぱいに。縁取り・影・斜め・集中線。動画サイトのサムネ風。
- 多いカテゴリ：動画編集・ショート動画。
- 売れている度合い：動画系の上位の半分近く。
- 色：赤×黄×黒、または白×青。派手。
- 文字：主役1語が幅の8〜9割。下に価格か実績を1行。
- うちで使えるか：使える。ただし安っぽく見えやすいので、うちの上品なサンプル動画とは相性が悪い。使うなら②ロゴ動画の「動く」の一語だけ、など一点使いにする。

### P3. 本人・人物型（写真または似顔絵）　★★★
- 見た目：右か左1/3に人物（笑顔・腕組み・スーツ）。残りに見出しと実績。似顔絵イラストやキャラクターで代用している人も多い。
- 多いカテゴリ：レッスン・コンサル・HP制作・士業。
- 売れている度合い：上位のおよそ4分の1。レッスン系では特に強い（「誰に教わるか」が商品だから）。
- 色：青・白が多い。
- うちで使えるか：うちのルールで素材の顔写真は使わない。オーナー本人の写真・似顔絵を使うかはオーナーが決めること。使わない場合は P10（マスコット）か P6（画面を見せる）で代える。

### P4. 作品グリッド型（実物を並べる）　★★
- 見た目：実際に作ったロゴ・チラシ・サイトを6〜12個、タイル状に並べる。文字は帯1本だけ。
- 多いカテゴリ：ロゴ・チラシ・パンフレット・イラスト。
- 売れている度合い：デザイン系の上位では定番。「腕前が一目でわかる」。
- 色：作品の色にまかせる。地は白か黒。
- うちで使えるか：**使える。サンプル動画4本のコマを並べれば今日作れる**。

### P5. 端末モックアップ型（パソコン・スマホに作品を入れる）　★★★
- 見た目：ノートパソコン＋スマホの画面に、実際に作ったサイトや動画を表示。HP制作ではほぼ標準装備。
- 多いカテゴリ：HP制作・LP・アプリ・ショート動画（スマホ縦画面）。
- 売れている度合い：HP制作の上位24件のうち半分ほどに端末が写っている。2枚目以降は「端末＋サイト全体の縦長スクショ」を何枚も続ける出品が多い。
- 色：白・ベージュ・薄い木目など明るい地が多い。
- うちで使えるか：**使える**。端末の枠は自分で描く（他社の製品写真・ロゴは使わない）。

### P6. 作品1枚ドーン型（文字ほぼなし）　★★
- 見た目：作品そのものを全面に。文字ゼロか、すみに小さく。
- 多いカテゴリ：イラスト・MV・アニメーション。
- 売れている度合い：絵で勝負するジャンルでは上位常連。
- うちで使えるか：①でサンプル動画の一番きれいなコマ（料理・店内）を全面に使う案として使える。ただし何のサービスか分からなくなるので、帯1本（「写真→15秒動画」）は入れる。

### P7. 価格ドーン型　★★
- 見た目：「5万円」「49,000円」「月3,000円」「1本4,500円」を主役に。まわりに「コミコミ」「修正無制限」など。
- 多いカテゴリ：HP制作・保守・動画編集の安価帯。
- 売れている度合い：安さで選ばれる価格帯では強い。上位にも複数。
- 色：白地にマゼンタや赤の数字。黄色い帯。
- うちで使えるか：使える。④保守（月5,500円）、③HP（66,000円・月額なし）と相性がよい。

### P8. お悩み呼びかけ型　★★
- 見た目：「〜で放置中のあなたへ」「〜が分からない人へ」「〜迷子、今日で卒業」。相手の状況を一言で言い当てる。
- 多いカテゴリ：保守・レッスン・診断系。
- 売れている度合い：保守・レッスンの上位に数件。評価が数十件の出品にも見られた。数字バッジを持たない人でも使える型。
- 色：明るい地＋太い黒文字、または青地＋黄色文字。
- うちで使えるか：**使える。評価0件のうちに一番向いている**。

### P9. 写真背景＋上品な明朝型（高級路線）　★★
- 見た目：落ち着いた写真（オフィス・夜景・木目）に、細めの明朝体でコピー。余白多め。金の細線。
- 多いカテゴリ：高単価のHP制作・コンサル・店舗PR動画。
- 売れている度合い：高価格帯（10万円以上）で多い。安いサービスには少ない。
- うちで使えるか：うちのサンプル動画（居酒屋・美容室）の雰囲気と合う。①で使える。ただし文字が細くて小さいと一覧で読めないので、主見出しだけは太く。

### P10. キャラクター・マスコット型　★★
- 見た目：動物や似顔絵キャラが吹き出しでしゃべる。親しみやすい。
- 多いカテゴリ：動画編集・レッスン・初心者向け。
- 売れている度合い：本人写真を出さない人の代わりの手として上位にも多い。
- うちで使えるか：使える。亀（タートル）のキャラを自作すれば、うちだけの顔になる。5出品に共通で使える「目印」にもなる。

### P11. ビフォーアフター型　★
- 見た目：左に「前」、右に「後」、まん中に矢印。
- 多いカテゴリ：音声の整音・資料の作り直し・サイト修正。
- 売れている度合い：数は少ないが、変化が売りのサービスでは一目で伝わる。
- うちで使えるか：**①に最適**（写真数枚 → 動画）。②（止まったロゴ → 動くロゴ）にも。

### P12. 料金表・プラン比較型　★
- 見た目：3列の表（月4本／8本／12本など）と価格。
- 多いカテゴリ：月額・まとめ買い系。
- うちで使えるか：1枚目には向かない（文字が小さくなる）。2枚目以降で使う。

### P13. チェックリスト・箇条書き型　★★
- 見た目：見出し＋チェック3〜4個。
- 多いカテゴリ：全部。
- 売れている度合い：上位にもあるが、**それだけで勝負している画像は少ない**。上位では必ず「人物」「端末」「数字バッジ」のどれかと組み合わさっている。
- うちで使えるか：単独では使わない（前回の失敗の型）。

### P14. 白地に文字だけ型　★
- 見た目：白い地に黒い文字2〜3行だけ。
- 売れている度合い：評価700件超・2,000件超の出品にあった。**実績があるから通用しているだけ**。新規がまねしても埋もれる。
- うちで使えるか：使わない。

### P15. 黒×金のラグジュアリー型　★★
- 見た目：黒地に金のふちどり・金文字・光の粒。
- 多いカテゴリ：動画編集・店舗PR動画・副業系。
- うちで使えるか：使えるが、うちに一番近い競合（お店向け15秒PR動画で評価1,000件超）がこの型。**同じ型にすると実績数で負けて見える**ので、うちは逆の「明るい・写真が主役」に振る。

## 3. 2枚目以降の画像の作り方（個別ページで見たこと）

売れている出品は、1枚目と同じ色・同じ書体で4〜10枚をそろえている。並べ方はだいたいこの順：

1. 表紙（上のどれかの型）
2. ほかとの違い（「ふつうの〇〇」と「うち」の2列くらべ）、またはお悩み3つ
3. 制作事例（HPは端末モックアップ＋縦長スクショを1件1枚で何枚も。動画は業種別のコマ）
4. 依頼から納品までの流れ（4〜5ステップ、アイコンつき）
5. 含まれるもの・料金・オプション
6. （レッスン）講師紹介 → 進め方 → こんな方におすすめ → 次のステップ

うちの前回は1枚だけ。**事例の画像がないのが一番の差**。

## 4. 売れている画像と、評価0件の画像のちがい

| | 売れている側 | 評価0件にありがち |
|---|---|---|
| 主役 | 作品・人物・数字のどれか1つが大きい | 主役がない。見出しと箇条書きが同じ重さ |
| 証拠 | 実物・実績数・顔のどれかがある | 何も見せていない。アイコンや図形だけ |
| 色 | 明るい地か、写真。出品ごとに雰囲気がちがう | 紺・濃い緑のベタ塗り＋白文字。どれも同じに見える |
| 文字 | 主役は幅の7〜9割。小さく縮めても読める | 小さい説明文が何行も。端で文字が切れている |
| 相手 | だれ向けか書いてある（お店向け、初心者向け） | サービス名を言っているだけ |
| 手ざわり | 写真・手描き・キャラなど人の気配 | 画面設計図のような、機械的な仕上がり |

共通点トップ3：
1. **証拠が1枚目に入っている**（作品そのもの／実績の数字／本人）。
2. **主役が1つで、縮めても読める**（一番大きい要素が画面の半分前後を占める）。
3. **だれの、どんな困りごと向けかが一言で分かる**。

## 5. 前回のうちの画像（01〜05）はどこに当てはまるか

正直に書くと、**「評価0件にありがち」の列にほぼ全部当てはまる**。

- 型は P13（箇条書き）単独。紺のベタ塗り＋白文字＋チェック3つ＋価格の枠。新着の評価0件に、これとそっくりな構図の画像が何枚もあった（濃い地色・小さな説明・自動で組んだような見た目）。一覧で並ぶと区別がつかない。
- 作品がゼロ。動画を売るのに動画のコマがなく、HPを売るのにサイトの画面がない。図形で描いた写真アイコンやスマホの絵は、証拠にならない。
- 5枚とも同じ型なので、買う人から見て「どれも同じ人が機械的に作った」印象になり、出品ごとの魅力が出ない。
- 右下の図が小さく、180px幅に縮めると見出し以外はほぼ読めない。
- だれ向けかが書いていない（お店向けなのか、個人向けなのか）。
- よかった点もある：見出しは大きく、価格は読める。文字切れもない。直すべきは「型」と「証拠」。

## 6. 作るときの決まり（デザイン担当のチェック表）

1. まず「証拠は何を見せるか」を決める。決まらないなら作り始めない。
2. 5出品で型を変える。となり同士で同じ型・同じ地色にしない。
3. 主役は1つ。見出しは12文字以内、補足は2つまで。
4. 180px幅に縮めて読めるか確認。上下115pxに大事なものを置かない。
5. うその実績・順位・お客さまの声を入れない。評価0件のうちは「約束の数字」と「サンプル」で勝負。
6. サンプルは「サンプル（架空のお店）」と小さく明記する。
7. 人の顔が写るコマ、他社のロゴ・商標（動画サイトやSNS、AIサービス、端末メーカーのマーク）は使わない。サービス名は文字だけで書く。
8. お客さまの名前・電話・住所が写るものは使わない。
9. 他社の画像をなぞらない。型（考え方）だけ借りて、色・配置・言葉はうちのものにする。
10. 素材の出どころを記録する（下の表）。
11. 1枚目だけで終わらせない。2枚目以降（事例・流れ・含まれるもの）を最低3枚そろえる。

## 7. 5出品それぞれの推薦

### ① 写真から作る15秒AI動画（9,800円）
- **案A：ビフォーアフター型（P11）＋作品のコマ【第一候補】**
  左に写真が3枚重なった絵、矢印、右にスマホ縦画面3つ（居酒屋の炭火・刺身・美容室の店内のコマ）。見出し「写真を送るだけ。15秒のお店動画」。価格は右下に丸で。地色は白〜生成り。
  理由：変化が売りのサービスで、一目で「何がどうなるか」が伝わる。競合の黒×金と逆の明るさで目立つ。
- 案B：作品1枚ドーン型（P6/P9）　居酒屋の炭火のコマを全面に、帯で「写真→15秒動画　9,800円」。食べ物の写真は一覧で一番目を引く。
- 案C：作品グリッド型（P4）　4業種のコマを2×2で並べ「飲食・美容・サロン・工務店」。2枚目に回してもよい。
- 2枚目以降：業種別サンプル4枚／流れ（写真を送る→確認→納品）／入っているもの（ナレーション・字幕・BGM）。

### ② ロゴを動かすアニメ動画（14,800円）
- **案A：コマ送り型（P11の応用）【第一候補】**
  タートルアドのロゴが「線→形→色→光る」と4コマで出来上がっていく様子を横に並べ、残像や動きの線をつける。見出し「あなたのロゴが、動く。」
  理由：検索しても本物のロゴアニメの出品が上位に少なく、「動いている感じ」を見せた画像はほとんどなかった。見せた者勝ち。
- 案B：使いどころモックアップ型（P5）　動画の冒頭・SNSのプロフィール・サイトの一番上、の3場面にロゴが入っている絵（枠は自作、他社マークなし）。「どこで使うの？」に答える。
- 案C：太文字ポスター型（P2）一点使い　「動く」の2文字だけ特大でぶらし、下にロゴ。
- 先に必要なもの：自社ロゴで実際に5秒のサンプル動画を1〜2本作る（架空の店のロゴを自作して増やすとなおよい）。実物がないまま画像だけ作らない。

### ③ 買い切りホームページ（66,000円）
- **案A：端末モックアップ型（P5）＋価格【第一候補】**
  パソコンとスマホの枠に実際のサイト画面。見出し「月額なしのホームページ　3ページ 66,000円」。地は明るいベージュか白。
  理由：HP制作の上位はほぼこの型で、買う人は「どんな見た目になるか」を最初に見る。型は王道でよく、言葉（買い切り・月額なし）でちがいを出す。
- 案B：価格ドーン型（P7）　「66,000円」を主役に、「買い切り／スマホ対応／名義はお客さま」を3つ。
- 案C：お悩み呼びかけ型（P8）　「毎月の支払いなしで、ホームページを持ちたい方へ」。
- 先に必要なもの：デザイン例。自社サイトだけだと1件なので、サンプル動画の素材（居酒屋・美容室・工務店）で**架空のお店のトップページ見本を2〜3枚作る**。「デザイン例（架空のお店）」と明記。2枚目以降は1件1枚で見せる。

### ④ ホームページ月額保守（5,500円）
- **案A：お悩み呼びかけ型（P8）【第一候補】**
  「ホームページ、作ったままになっていませんか？」＋亀のキャラか、ほこりをかぶったパソコンの手描き風イラスト。下に「月5,500円でおまかせ」。地はやさしい緑か水色。
  理由：保守・更新代行の上位に、この型で月額をはっきり書いた出品があった（見た範囲では少数なので、効き目は出してから数字で確かめる）。③と色も型も変えられる。
- 案B：価格ドーン型（P7）　「月5,500円」を主役に、やること4つ（更新・バックアップ・文章直し・写真差し替え）をアイコンで。
- 案C：安心の対比型（P11の応用）　「ほうっておくと：表示くずれ・古い情報」→「おまかせすると：いつも最新」。
- 注意：「いつでも解約OK」は強い言葉なので1枚目に入れる。

### ⑤ 生成AIの1対1レッスン（60分 11,000円）
- **案A：お悩み呼びかけ型（P8）＋画面を見せる（P5）【第一候補】**
  見出し「AI、何から始めればいい？」。右にパソコンの枠、中に自作の会話画面（質問と答えのやりとりを日本語で。他社マークなし）。下に「60分・1対1・画面を見ながら」。地は白＋明るい青や黄。
  理由：レッスンの上位は「人物」か「初心者への呼びかけ」。顔を出さないなら呼びかけが一番強い。
- 案B：キャラクター型（P10）　亀の先生が画面を指さして教えている絵。親しみやすさで勝負。5出品共通の目印にもなる。
- 案C：本人型（P3）　オーナーの写真か似顔絵＋肩書き。レッスンでは一番効く型だが、顔を出すかはオーナーの判断。
