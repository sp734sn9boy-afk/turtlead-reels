# ココナラ出品画像 買い手目線の調査

作成：2026-11-21 営業担当（調査と分析のみ。画像は作っていません。コミットしていません）
対象：うちの5本（①写真からAI動画9,800円 ②ロゴアニメ14,800円 ③買い切りHP66,000円 ④HP月額保守5,500円 ⑤生成AIレッスン60分11,000円）
想定する買い手：地方の小さなお店・会社（美容室・飲食店・工務店・士業など）の店主や担当者、副業・個人事業主

---

## 0. 先に結論

- 買い手は一覧で**画像 → 価格 → 星と件数**の順に見て、ページを開いてから**作品（サンプル）・やりとりの丁寧さ・自分と同じ業種か**で決めている。
- 売れている出品のレビューで一番多い「決め手」は、作品の出来よりも**「丁寧」「早い」「初めてでも安心」「こちらの意図をくみ取ってくれた」**。つまり**人柄と進め方**。
- うちの今の5枚は、同じ紺色の型に「アイコン＋箇条書き＋値段」。きれいだが、**本物の作品も、人も、誰向けかも、会社であることも写っていない**。一覧で「AIが作った量産テンプレ」に見えやすい（これは私の見立て）。
- 実績0のうちは、**数字（販売数・順位）で勝負できない**。代わりに「本物のサンプル」「誰が作るか（会社・情報誌の発行元）」「進め方がわかる」の3つで不安を消す。

## 2. 実績0の新しい出品者は、画像で何を見せると不安が減るか

### 2-1. わかったこと

- ココナラのWeb制作カテゴリでは**販売実績0件の出品が約8割（79.1%）**、全体でも約74%、生成AI活用カテゴリは88.3%という出品者の独自集計がある（ココナラ内ブログ。元記事は現在削除済みで、検索結果の要約でのみ確認＝**未検証**）。→ 買い手は「実績0」の出品ばかり見ている。**実績0そのものより「中身が見えない」ことが嫌われる**、と考えるのが自然（推測）。
- 実績0から受注した制作者の体験として、**架空の会社のサンプルサイトを作って見せた**ことが受注につながったという話がある（検索結果の要約。https://library.libecity.com/articles/01M05CVVND7JPQ6W5YFHF4WWEN ）。
- ココナラ内ブログ（https://coconala.com/blogs/82069/784118 ）：実績が少ないうちは、**実際の制作物の画像を載せる／納期を「○日以内」と具体的に示す／返信の目安を書く／全出品でアイコンやロゴの雰囲気をそろえて信頼感を出す／安売りしすぎない（安すぎると不安）**。
- ココナラ公式（https://coconala.com/news/1307 ）：購入者は**経歴・ポートフォリオ・資格や執筆歴**を見るよう案内されている。→ 「地域情報誌を発行している会社」は、公式が言う「経歴」「執筆歴」にそのまま当てはまる。
- ココナラはお金を取引完了まで預かる仕組み（エスクロー）なので、買い手の「お金だけ取られる」不安は仕組みで小さくなっている。残る不安は**「思っていたのと違うものが来る」「話が通じない」**（レビューの裏返し）。

### 2-2. 実績0の不安を消す見せ方トップ3（提案）

1. **本物のサンプルを1枚目の主役にする**
   - 動画なら実際の1コマ（写真→動画の「前・後」）、HPなら実際のサイトの画面をスマホとパソコンに入れる。アイコンの絵ではなく本物。
   - 自社（タートルアド）や架空のお店で作ったサンプルでよい。架空なら2枚目以降に「サンプル（架空の店舗）」と小さく明記する（誤解を避けるため）。
2. **「誰が作るか」を見せる：会社であること＋鹿児島で地域情報誌を発行していること**
   - 例：「鹿児島で地域情報誌を発行する制作会社です」「お店の取材・広告づくりを続けてきた会社が作ります」。
   - 公式が言う「経歴・執筆歴」に当たり、**数字の実績の代わりになる、うちにしかない材料**。個人の副業出品が多い中で差が出る（推測）。
   - 顔写真はオーナー判断。出さない場合は、ロゴ＋「担当：○○（会社名）」でも「誰が対応するか」は伝わる。
   - ※情報誌の名前・URL・電話などの**連絡先は画像に入れない**（ココナラ外への誘導になるおそれ）。誌名を出してよいかは規約の確認が必要（未確認）。
3. **「頼んでから届くまで」を3ステップで見せる（2枚目）**
   - 例：「①写真を送る → ②確認用を見る → ③修正して納品」。レビューで一番多い決め手「丁寧」「分かりやすく誘導してくれた」「安心してお任せできた」を、**買う前に体験させる**。
   - 「ご購入前のご相談OK」も入れる（売れている出品のレビューの大半が「見積り相談」経由）。

**やらないほうがよいこと**
- 根拠のない「No.1」「実績多数」（実績0なので不可。ココナラの規約・景品表示法の面でも危ない）。
- 全部同じ紺色テンプレのまま。一覧に5本並ぶと同じに見え、中身の違いが伝わらない（見立て）。

## 4. 5本それぞれの画像に入れるべきこと

共通ルール（1枚目）
- 文字・顔・作品は**中央寄せ**（上下120pxは切れる前提、右下は空ける）。
- 大きい文字は**1行で何が手に入るか**＋**誰向けか**。小さい字は一覧ではほぼ読めない（推測：スマホの一覧では1枚目がかなり小さく表示される）。
- 値段は大きく入れてよい（一覧でも価格は表示されるが、うちは「安さ」が武器になる帯なので）。
- 5本で**色を変える**か、少なくとも「本物の作品の写真」で見分けがつくようにする。ロゴと会社名の位置はそろえる（統一感＝信頼）。
- 「AIで作る」ことは隠さない（ココナラのAI利用ルール。出品文と同じく明記）。

### ① 写真から作る15秒AI動画（9,800円）
- **1枚目に必ず**：「スマホの写真→動く縦型動画」の**前・後が一目でわかる実物**（お店の写真が動画のコマになっている絵）／「撮影いらず・写真だけでOK」／「お店のInstagram・リールに」／9,800円
- **2枚目以降**：サンプル動画の連続コマ（飲食・美容室・工務店など業種別に2〜3本）／「①写真を送る②確認用を見る③修正して納品」／入っているもの（字幕・BGM・ナレーション）／修正回数と納期（具体的な日数）／「購入前のご相談OK」／鹿児島で地域情報誌を発行する会社が作っていること
