### 本文（ここから下をnoteに貼る）

こんにちは。鹿児島の合同会社turtle ad（タートルアド）です。地域情報誌の発行や、ホームページ・動画の制作をしています。

「最近はInstagramでも動画がよく見られているらしい」
「うちも動画を出したほうがいいのは分かっている」

でも、

- 撮影する時間がない
- 自分が顔を出してしゃべるのは、ちょっと恥ずかしい
- 編集のやり方が分からない

こんな理由で、動画が後回しになっているお店や会社は多いのではないでしょうか。

この記事では、**撮影なし・顔出しなしで、手元にある写真からお店の紹介動画を作る方法**をお話しします。使うのは「AI」です。難しそうに聞こえるかもしれませんが、お店の方にやっていただくのは「写真を選んで送る」ことだけ、という形も作れます。

実際の作例、作るときの流れ、費用の目安、そして「自分で作る」「プロに頼む」のどちらが合っているかの比べ方まで、順番にまとめました。

#### 1. 「AI動画」って、どんなもの？

ここで言う「AI動画」は、ざっくり言うと次のようなものです。

- **お店の写真を何枚かつなげた、縦長の短い動画**（スマホの画面いっぱいに映る形です）
- そこに、**AIが読み上げる声（ナレーション）**と、**字幕**、**BGM（背景の音楽）**を付けたもの

長さは15秒前後。Instagramの「リール」（短い縦型動画を流す機能）や、YouTubeの「ショート」（同じく短い縦型動画）に、そのまま載せられる形です。

ポイントは、**新しく撮影しなくていい**こと、そして**誰も顔を出さなくていい**ことです。声はAIの音声読み上げを使うので、店主さんがカメラの前でしゃべる必要もありません。

#### 3. 作るときの流れ（4ステップ）

私たちに頼んでいただく場合の流れは、こんな形です。

**ステップ1：LINEで相談**
お店のこと、動画でいちばん伝えたいことを教えてください。「新しいメニューを知ってほしい」「初めての人に、お店の雰囲気を知ってほしい」など、ざっくりで大丈夫です。相談とお見積りは無料です。

**ステップ2：写真を送る**
スマホで撮った写真を5〜10枚お送りいただきます。撮り方はLINEでご案内します。

**ステップ3：動画を作る**
いただいた写真と情報をもとに、ナレーションの原稿、字幕、BGMを入れて動画にします。

**ステップ4：確認して、納品**
できあがった動画を見ていただき、直したいところがあれば修正して納品します。文字・色・順番などの軽い修正は2回まで料金に含まれます。

納期は、ご入金と写真・基本情報が届いてから、**最短3営業日**です（内容や混み具合によって前後します）。

#### 4. 用意していただくもの

**写真5〜10枚**
- スマホを**縦向き**にして撮ったもの
- 外観、店内、料理や商品など
- **いまのお店の様子**に合っているもの
- ご自分で撮った写真か、使ってよいと許可をもらっている写真

※お客さまの顔が写っている写真を使いたい場合は、事前にご相談ください。

**基本情報**
- 店名（読み方も）
- 営業時間・定休日・予約方法
- いちばん伝えたいこと

写真の撮り方のちょっとしたコツは、「明るい時間に撮る」「縦向きでそろえる」「同じ場所を何枚も撮るより、外観・入口・店内・商品と場所を変える」の3つです。これだけでも、動画にしたときの見やすさがかなり変わります。

#### 5. 「使える写真がない」ときは

「最近の写真がほとんどない」という場合も、方法があります。

**① AIで作る「イメージ写真」**
AIで、お店の雰囲気に合ったイメージ写真を作ります。5枚までは無料、6枚目からは1枚550円（税込）です。
この場合、動画には「※写真はイメージです」と表示します。また、**実在しないメニューや、実物より豪華な盛りつけは作りません。**見た人が来店したときに「思っていたのと違う」とならないようにするためです。

**② 撮影代行**
鹿児島県内のみ対応しています。場所によって料金が変わるため、別にお見積りします。

#### 7. 自分で作る？ プロに頼む？ 比べてみました

最近は、スマホのアプリやAIのサービスを使えば、自分で動画を作ることもできます。どちらが良い・悪いではなく、**お店の状況に合うほう**を選ぶのがいちばんです。

| | 自分で作る | プロに頼む |
|---|---|---|
| お金 | アプリによっては無料で始められる（機能や、お店の宣伝に使ってよいかの条件はアプリごとに違う） | 1本9,800円〜（当社の場合） |
| 時間 | アプリの使い方を覚える時間＋作る時間がかかる | 写真を選んで送る時間と、確認の時間だけ |
| 中身 | 自由に何度でも作り直せる | 「何を、どの順番で伝えるか」の組み立てから任せられる |
| 気をつけること | 音楽や画像を使ってよいか（著作権）を自分で確かめる必要がある | 料金がかかる。軽い修正の回数に上限がある |

**自分で作るのが向いている人**
- スマホの操作が好きで、作ること自体を楽しめる
- 毎日でも、気軽に投稿したい
- まずはお金をかけずに試してみたい

**頼むのが向いている人**
- とにかく時間がない
- 「何を言えばいいか」から一緒に考えてほしい
- 音楽や画像の使い方で、トラブルになるのが心配
- お店の顔になる1本を、ちゃんとした形で作っておきたい

「最初の1本はプロに頼んで、型ができたら自分でも作ってみる」という使い方もおすすめです。

#### 8. 私たち自身も、毎日AI動画を出しています

少し裏話をすると、私たちタートルアドでも、**AIで作った短い動画を毎日、InstagramやYouTubeに投稿する仕組み**を動かしています。

流れはこうです。

1. AIを使って、その日の短い動画を作る
2. 内容に間違いがないかを確認する（確認が済んでいないものは投稿しない）
3. 決まった時間に、自動で投稿する
4. 投稿できたかどうかが、スマホのLINEに届く

「毎日投稿したいけれど、毎日はとても手が回らない」というのは、私たちも同じでした。だからこそ、**作る・確かめる・載せる**を仕組みにしてしまう、という考え方をとっています。
AIで作った動画には、その旨の表示（AIで作ったことのラベル）も付けています。

#### 9. AI動画を作るときに気をつけていること

AIは便利ですが、使い方を間違えると、お店の信用を下げてしまうこともあります。私たちは次のことを守っています。

- **AIで作った写真を使うときは「※写真はイメージです」と表示する**
- **実在しないメニューや、実物より良く見せる盛りつけは作らない**
- **お預かりした写真や情報は、動画を作る目的にだけ使う**
- 美容・健康に関わる内容では、「効果には個人差がある」などの注意書きを入れる
- お酒を扱うお店では、「20歳未満の飲酒は禁止」の表示を入れる

「見た人が、実際に来て、がっかりしない動画」を作ることが、結局はいちばんの集客になると考えています。
