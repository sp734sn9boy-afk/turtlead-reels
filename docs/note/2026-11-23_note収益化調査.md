## 理由（数字）
1. noteで売れているのは実用ノウハウ。売上上位20%の平均価格は実用ノウハウ系1,842円、読み物系983円（約1.9倍）。伸びているのは「テクノロジー・AI活用」「SNS運用」「複業・在宅ワーク」。（note社 2026年1月7日発表、約30万件の分析／二次情報）
2. note全体は伸びている。メンバーシップ売上 前年同月比+81.3%、購入件数+86.3%、売上が出たクリエイター数+100.5%（2025年11月時点）。有料記事の売上+26.8%。note社の売上は2026年11月期3Q累計40億5,800万円（+33.2%）。
3. ただし、AI系の有料記事は競合が強い（「note×AIで2億円」の書籍5万部など）。「AIに任せた記事は売れない」「最初の100円が売れるまで466日」という声もある。フォロワーゼロの新しいアカウントが有料記事で大きく稼ぐのは難しい（推測）。
4. 1件の重さが違う。980円の有料記事（カード払い）の手取りは約838円（事務手数料5%＋利用料10%、振込手数料270円は別）。**AI動画1本9,800円 ＝ 有料記事約12本分、月4本プラン29,800円 ＝ 毎月約36本分。** 受注1件の方が早い。
5. 相場の中でタートルアドの値段は手頃。リール制作代行の相場は1本8,000円〜15万円（制作会社ブログ）、ココナラは5,000円〜数万円、「2本1万円」の出品も。地方の会社のAI動画サービスは1本3万円。タートルアドは1本9,800円・3本24,800円・月4本29,800円で、店舗の作例（美容室・工務店・塗装）を持っているのが強み。
6. noteで「美容室×リール」「美容室オーナー必見」型の記事は既にある（AI副業らぼ、さかいあやこ、Skywalk）。多くは「作り手向けの副業ノウハウ」で、**「店主が頼む側」向けに実例と料金を見せる記事は少ない**（検索した範囲で）。ここが空いている。
7. ほかの会社の解説でも「読まれる」と「問い合わせが来る」は別もので、記事→サービスページへの道筋が大事とされている。
8. おまけ：note社は2026年11月18日、AIがnote記事を参照した分の対価をクリエイターに分配すると発表（12月中旬支払い予定）。実例のある役立つ記事は、こちらでも少し得になる可能性がある（金額は不明）。
