# note 自動入力の手順（パソコンの Claude 用）

パソコンの Claude（デスクトップアプリ＋Chrome の Claude 拡張）が、毎朝の審査済み記事を note に入力するための手順書です。
クラウドのセッションからはオーナーのパソコンやブラウザを操作できないため、この作業はパソコン側で動かします。

## 前提
- Chrome で note にログイン済みであること
- Chrome に Claude の拡張機能（提供元 Anthropic）が入っていること
- Claude に n8n のコネクタがつながっていること

## 記事の取り出し方
- n8n のデータ表「note下書き表」（dataTableId: mS8mGPFZqdvJvctv、projectId: x38o23h5wCHsgCOg）
- 対象：status が「合格」または「要修正」で、まだ note に入れていない行（posted 列が空。列がなければ作る）
- 本文：要修正なら revised 列、合格なら article 列を使う
  - 1行目＝タイトル
  - 「――――― ここから有料 ―――――」より上＝無料部分、下＝有料部分
- 値段：price 列（例「480円」）
- 見出し画像：/home/user/turtlead-reels/img/note/note_header_YYYYMMDD.png（その日の分があれば）。テンプレートは img/note/note_header_template.html

## note での入力手順
1. Chrome で note を開き、「投稿」→「テキスト」で新しい記事を作る
2. タイトル欄にタイトルを入れる
3. 本文欄に、無料部分→有料部分の順に貼る。「##」で始まる行は見出しにする
4. 見出し画像があれば、記事上部の画像欄から設定する
5. 「公開に進む」→ 販売設定で「有料」を選び、値段を入れる
6. 有料エリアの境界線を「ここから有料」の位置に合わせ、線の文字は消す
7. ハッシュタグを3〜5個入れる（テーマに合う一般的な言葉。人名・会社名は入れない）
8. **公開モードの設定に従う**
   - 下書きモード（初期設定）：「下書き保存」を押して終わり。公開ボタンは押さない
   - 公開モード：オーナーが「公開まで任せる」と決めた場合だけ「投稿する」を押す
9. note下書き表の posted 列に、入力した日時と「下書き」または「公開」を書く（書き込みは n8n「note審査結果を書き込む」を使うか、仕組み担当に依頼）
10. 結果（タイトル・下書きか公開か・note の URL）をオーナーに短く報告する

## 守ること
- 1日1本まで。連続投稿や大量操作はしない
- 画面が見慣れない状態になった、ログインを求められた、エラーが出た、などのときは無理に進めず止まってオーナーに知らせる
- 公開・値段の変更・削除など取り消しにくい操作は、公開モードでない限りしない
