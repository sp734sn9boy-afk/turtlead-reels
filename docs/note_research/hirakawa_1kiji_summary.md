# YouTube「noteで0→月100万円 完全ロードマップ」（平川さん）要点メモ

オーナーが文字おこしした動画（約95分）を、リーダーが要約したもの。2026-11-18。
※話し手の実績（1記事で5年平均 月136万円、副産物込み累計3.4億円など）は本人の申告で、こちらでは確かめていない。

## 結論
- noteの売上 ＝ 単価 × 販売数 ＋ 副産物（noteをきっかけに生まれる別の売上）
- 勝ち方は「1記事 × 高単価 × 副産物」（本人は「1記事ノート戦略」と呼ぶ）
- 数を増やすより単価を上げ、売って終わりにせず副産物を育てる

## 9割が止まる3つの失敗
1. 数百〜数千円の記事を量産する（書くのをやめた瞬間に売上が止まる「自転車操業」）
2. メンバーシップ（月額）を主体にして、毎月5〜10本の更新に追われる
3. フォロワーを増やそうとSNSに張り付く
- AIで「それっぽい記事」を誰でも量産できるようになり、量産の道はさらに報われなくなった。AIは量産ではなく「1記事を磨く」ことに使う
- 共通点：全部「自分の売上と作業」が中心で、「読者が成功できるか」が抜けている

## ステップ0：土台
- 自分は何者か（自分にしか語れない立ち位置。実績がなくても「少し前の自分の悩みを今解決できている」でよい）
- 指標は売上ではなく「読者が成功したか」
- 時間の物差しは「今月いくら」ではなく「3年後にいくら」

## ステップ1：何を売るか
- noteはゴールではなく「入り口商品」。その先の副産物につなげる
- ノウハウではなく「変化（AからBへ）」を売る
- テーマ ＝ 普遍性（5年後も価値がある。流行りものは賞味期限切れ）× 需要（お金を払ってでも解決したい悩み）× 自分の経験
- ターゲットは「悩みは深く、間口は広く」

## ステップ2：作り方（読者が出会う順番で作る）
- タイトル：変化と具体的な数字。煽らない（中身で約束できることだけ）
- 見出し画像（サムネ）：スクロールを止める。悩みや変化を短い言葉で。キラキラさせない
- 無料パート：ここで購入の8割が決まる。共感 → なぜ自分が語れるか → 読むとどう変わるか → 核心は有料で。冒頭の数行（10秒）に一番力を入れる
- 有料パート：情報を並べず、読者をゴールまで階段で連れていく（全体像 → 手順 → つまずき所を先回り → 実例 → 行動を促す）。途中に小さなワークを入れる
- noteは装飾が少ないので、見出しと余白で読みやすくする

## ステップ3：値段
- 値段は先に決める（「プライスファースト」。高い値段を先に決めると中身の基準が上がる）
- 安売りは「中身がなさそう」に見え、本気でない人を集める。高単価は本気の人だけを残すフィルター
- 払う額より返ってくるものが大きいことを、正直に見せる（コンサル・スクールと比べる等）。嘘はつかない
- 低単価・無料は「入り口」「認知」の役割として使い分けてよい。ただし大半の人は高単価1本に集中でよい
- いきなり高くできなければ、中身を足しながら予告して値上げ。既存の購入者は大事に（追加分は無料で届ける）

## ステップ4：届け方
- SNSは「知ってもらう場所」、noteは「売る場所」。役割を混ぜない
- 人は「知る → 信頼する → 買う」の順で動く
- 公式LINE・メルマガで見込み客と直接つながる
- noteは検索に強い。悩んでいる人が打ち込む言葉をタイトル・本文に入れる。AI検索の参照元としてもnoteは上位（YouTubeに次ぐ2位というデータを紹介）
- 最強の集客は口コミ。期待を超えたときに生まれる。「読んだ直後の感想」より「実際に変わった」口コミが強い

## ステップ5：副産物と資産化（本丸）
- 副産物の例：読者が成功する過程で必要になるツール・業者の紹介（倉庫・デザインなど）。使い続ける限り継続して入る
- 読者の成功と自分の売上が一致する仕組みにする
- 記事は売ってからが始まり。質問やつまずきを反映して書き直し続ける（リライト）
- 買ってくれた人を名簿にする（いちばんの財産）。ファンに育てる

## 時間の順番
- 0→月10万円：土台を決めて、高単価の1記事を本気で作る（1〜3か月）。量産・毎日のSNSは捨てる
- 10万→30万円：作った1記事を届ける（SNS→プロフィール→note・公式LINE）。購入者の名簿化を始める。副産物はまだ
- 30万→100万円：リライトで磨く、副産物を設計、ファンに育てる
- フェーズを飛ばさないことが最短ルート
