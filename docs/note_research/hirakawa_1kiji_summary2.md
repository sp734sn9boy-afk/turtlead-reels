# YouTube 2本目「1記事を企画→値付け→販売→育成→1億円までの全工程」（平川さん）要点メモ

オーナーが文字おこしした2本目（約6時間半）を、リーダーが要約したもの。2026-11-19。1本目の要約は hirakawa_1kiji_summary.md。
※話し手の数字（1記事経由4億円、製造販売記事は単体8,000万円超など）は本人の申告で、こちらでは確かめていない。

## 1本目から増えた・具体的になった点

### 書く前に決める3つ（最初の1か月は記事を書かない）
1. **自分の棚卸し**：音声入力で20〜30分しゃべり、AIに「人の役に立つ経験」「当時何を正しいと思い込んでいたか」を抜き出させる。**AIに経験・体験談・数字を作らせない**（整理だけ任せる）。失敗と抜け出し方（書き手の痛み）を必ず拾う。読者は「一番苦しかった頃の自分」
2. **テーマと変化**：「この記事を読み終えたら、読者は〇〇ができるようになる」を一文で言えるまで書かない。ゴールは1つ。変化を盛らない
3. **値段（プライスファースト）**：書く前に決める。目安は**5,000〜30,000円**（3万円までは小遣いの範囲で相談なしに決められる人が多い）。事業者向けなら上でもよい

### 需要の確かめ方
- 人からよく相談されるか／SNSで発信して「詳しく教えて」「保存」が多いか（いいね数ではない）／同じ悩みに本・講座・有料記事でお金が動いているか。競合がいる＝お金が動く市場
- テーマは5年後も悩む人がいる普遍的なもの（リンディ効果）。ツールなど枝葉は差し替えればよい
- 値段の物差しは「ノートの中の相場」ではなく「同じ悩みを他の方法で解決したらいくらか」（コンサル・代行・教室など）

### 高い値段に見合う「手助け」
テンプレート・ワークシート／チェックリスト・診断／限定動画や資料／質問フォーム・追加資料・購入者の場／回数を決めた個別サポート（時間を使うので注意）。文字数を増やして値段を正当化しない

### 記事の骨組み
- 無料パート＝目の前の売上。4ブロック：①冒頭の一撃（悩みを言い当てる。自己紹介から始めない）②共感（自分も同じだった）③信頼（なぜ語れるか）④変化の提示（読むとどう変わるか・購入者の声）。**自分を知らない初めての人向けに**書く。事例は1つの話に1つ
- 有料パート＝未来の売上（成功→口コミ）。地図（全体像、売れた後まで）→ステップ→つまずきの先回り→実例→行動。**最初のステップは読んだ日にできる簡単さ**。途中に小さなワーク。最後に道具（チェックリスト等）を渡す。書かないことも決める
- 書き方：見出し（箱）を先に並べる→箱ごとに音声で吐き出す→AIで整える→自分で整えて削る。80点で出し、出してから直す

### タイトル・サムネ・目次
- タイトル＝具体的な数字・事例＋約束する変化＋読者が検索する言葉。煽らない
- 見出し画像はタイトルと補い合う一言だけ。キラキラさせない
- **有料パートの目次は「買う前の最後の試し読み」**。「第1章 基礎」ではなく「読んだら何が手に入るか」で書く（変化を見せる型／問いかけ型／数字型／常識を否定する型／安心させる型を混ぜる）。スマホで見出しだけ読んで変化が伝わるか確認

### 出し方（静かに出す）
- 発売前から作っている途中を見せ、興味を持った人に公式LINE等へ登録してもらう。出すときは事実だけ伝える
- 「残り〇部で値上げ」「売り切れたら値上げ」の煽りはしない（期待を上げすぎると満足度・口コミが落ち、翌月に崖が来る）。還元するなら「発売から1週間だけ割引」のように期間で区切る
- **一度出したら値下げ・セールはしない**（先に買った人が損をする）。値上げは中身が増え＋成果の声が集まり＋信頼が上がったときに、理由と日付を予告して。無料パートに「内容の追加に応じて値上げすることがあります」と書いておく
- 返金申請はオフ（本気の人に届けるため）
- 見るべきは初月の売上ではなく、3か月後・半年後も売れ続けているか、購入者の声

### 届け方
- SNS＝知ってもらう（売り込まない）、YouTube＝信頼してもらう（長く見てもらえ、何年も見られ続ける）、note＝買ってもらう。プロフィール・固定投稿・概要欄で橋をかける
- 公式LINE・メルマガで直接つながる。noteは検索・AIからの流入もある（お守り）
- 最強は口コミ（友人・家族の推薦を83%が信頼）。目指すのは「読んだ感想」ではなく「やってみて変わった」口コミ。特典目当ての感想集めはしない（必要ならモニター）。紹介を頼むときは**PR表記必須（ステマ規制）**

### 売れた後の7つ
1. 買った直後の最初の一歩を「いつ・何を」まで決めてあげる
2. **購入者専用の名簿**（公式LINE・メール）を作る。「購入者限定資料はこのLINEから」等で登録理由を作る
3. 記事を直したら、どこを・なぜ直したかを伝える（購入者にはLINE、未購入者にはSNSで＝再販売のきっかけ）
4. 質問を集めて記事に反映（1件の質問の裏に同じ人が多数）。個別対応せず月1回の質問ライブなど1対多で
5. 有料パートの冒頭にアンケート（どこで知ったか・職業）
6. 時期を見て「その後どうですか」と成果の声を集め、許可を取って無料パートへ
7. 先に買った人を裏切らない（値下げしない、追加分は無料で届ける、補足を別商品で売らない）
- 依存させず、読者が自分で進めるようにする。「全員成功させる」とは言わない

### 育て方
- 公開日が一番未完成。直す場所は3つ：入り口（タイトル・見出し・書き出し＝見つけてもらう）／無料パート（買ってもらう）／有料パート（成果を出してもらう。まず削る、足すのは自分が実際にやったことだけ、図・表にする）
- 頻度の目安：公開1週間〜10日、1か月後、以後3か月ごと、1年以降は半年〜年1回。普段はメモに貯める
- 市場の空気が変わったら、中身ではなく入り口（発信の切り口・無料パートの「誰向けか」）を変える（リブランディング）。新テーマで作り直すのは一番リスクが高い

### 副産物（2階建て）
- 1階＝記事の売上、2階＝記事を読んで行動した人が必要になるものの売上（倉庫・ツール・業者の紹介など、使い続ける限り継続して入る）。2階にnote手数料はかからない
- 2階の種類：①他社サービスの紹介（時間を使わない、単価は低め）②自分で直接サポート（単価が高い、時間と責任がかかる）
- 作り方：読者の行動地図（記事を読んだ人が何をどの順にするか）を書き、各工程で必要になるものを並べる→自分が実際に使って良かったものだけ、記事の必要な場所に、体験談として紹介。報酬が出るものは明示。「これを使わないと実践できない」はNG
- 本気で行動する人が買うほど2階は伸びる＝高めの値段と相性がよい。2階を目的にしない

### 数字の見方
- noteの管理画面の「note経由」は読み返しや内部リンクで膨らむ。購入者アンケートでは「noteで知った」は1.5%しかいなかった例
- 見る数字：1PVあたりの売上（売上÷PV）／表示回数÷PV（1未満なら外から直接読まれている＝資産化）／ノーリファラーの割合／note経由とノーリファラーを除いた一番多い流入元／公式LINE登録者1人あたりの売上／アンケート。月1回5分、線で見る
- 1PVあたりの売上が低いなら、PVを増やす前に値段・変化の書き方・無料パートを直す
