1. 飲食店マップのとき、ホテルやレンタカーのお店に置こうと思ったのはなぜですか。ほかのお店の広告でも「誰が、どこで見るか」を決めるとき、お店の人に何を聞いていますか。

2. マップには、地図のほかに何を載せていましたか。見た人が迷わずお店まで来られるように、工夫したことがあれば教えてください。

3. 色を直すとき、ロゴや会社の雰囲気に合う色は、どうやって決めていますか。お店の人の原稿の色を変えるとき、実際にどんな言葉で伝えていますか。

4. 一番大きな文字には、何を書くと反応が良いですか。良かった例と、良くなかった例を1つずつ教えてください。

5. 求人の広告で、人が来た例はありますか。あれば「従業員募集」の一行と何が違いましたか。なければ「ない」で大丈夫です。今ならどうしたらいいと思うかも教えてください。

6. 工務店・自動車関係・塗装関係の広告で、それぞれ気をつけていることや、よくある失敗を教えてください。1つの業種だけでも大丈夫です。

7. 広告を出したあと、反応があったかどうかは、どうやって分かりますか。「それを見て来たよ」のような声は、どうやって集まってきましたか。

ありがとうございました。いただいた答えは、こちらで記事の文章に整えます。
