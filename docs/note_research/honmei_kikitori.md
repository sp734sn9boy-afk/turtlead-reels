## 第1回：私たちのこと・覚えている広告（15分）
ねらい：無料パートの「なぜ私たちが語れるか」と、記事全体の芯になる実例をつかむ

1. 地域情報誌（マイタウンガイドなど）を始めて何年になりますか。これまでに作った広告や原稿は、だいたい何本くらいですか。（「年に○本×○年」のような、おおまかな数で大丈夫です）
2. よく広告を出してくれるのは、どんな業種のお店ですか。多い順に3つ教えてください。
3. 反応が良かった広告で、覚えているものを1つ教えてください。何の業種で、前と何を変えたら電話や来店が増えましたか。
4. 反対に「お金をかけたのに反応がなかった」広告で、覚えているものを1つ教えてください。今思うと、何が原因だったと思いますか。
5. お店の人から、広告について一番よく聞く悩みや口ぐせは何ですか。（例：「何を書けばいいかわからない」「全部載せたい」）
6. お店の人が自分で書いてきた原稿を直すとき、いちばん多く直すところはどこですか。
7. この記事を読んだお店の人に、最後にどうなっていてほしいですか。ひとことで教えてください。

## 第2回：反応が出る1枚と出ない1枚の違い（15分）
ねらい：有料パートの中心「反応が出る1枚の決まりごと」を言葉にする

1. 広告を見てパッと「これは反応が出そう」「これは厳しい」とわかるとき、どこを見て判断していますか。上から順に教えてください。
2. 一番大きな文字（見出し）には、何を書くと反応が良いですか。良かった見出しと、良くなかった見出しの例を1つずつ教えてください。
3. 写真はどう選んでいますか。反応が良かった写真と、悪かった写真の違いは何ですか。（料理の寄り・人の顔・店内など）
4. 「初回○円」「この広告を見たと言えば○○」のような特典はつけたほうがいいですか。効いた特典と、効かなかった特典の例を教えてください。
5. 電話番号・地図・営業時間・駐車場などで、「これがないと電話が来ない」というものはありますか。
6. 文字や情報を詰め込みすぎたお店に、どう説明して減らしてもらっていますか。そのとき実際に言う言葉を、そのまま教えてください。
7. 業種によって変えていることはありますか。（飲食・美容・整骨院・工務店・習い事など）

## 第3回：作る手順とテンプレ（15分）
ねらい：読者がまねできる「手順」と「テンプレ（記入シート）」の材料を集める

1. お店から広告の依頼を受けたら、最初に何を聞きますか。打ち合わせで必ず聞く質問を、思いつく順に全部教えてください。
2. 聞いた話から原稿にするとき、どの順番で書いていますか。（見出しから？写真から？特典から？）
3. 「このお店の一番の売り」が、お店の人自身もわかっていないとき、どうやって見つけていますか。
4. 原稿ができたあと、出す前に確かめていることはありますか。チェックする点を教えてください。
5. お店の人が自分で作るなら、「最低限これだけは埋めて」という項目を5つに絞ると何になりますか。
6. 広告を出したあと、反応が出たかどうかはどうやって確かめていますか。お店の人に勧めていることはありますか。
7. 最近、原稿づくりにAIを使うことはありますか。使うなら、どこに使って、どこは人がやるべきだと思いますか。

## 第4回：つまずき所・実例・応用・LINE（15分）
ねらい：有料パートの「先回り」と「実例」、無料記事やInstagramの材料、LINEに来てもらう理由を決める

1. お店の人が広告づくりでつまずくところを、多い順に3つ教えてください。
2. 同じ考え方は、Instagramの投稿やGoogleマップの情報にも使えますか。使えるなら、どこが同じで、どこが違いますか。
3. 記事の実例として、お店の名前を伏せて紹介してよい広告はありますか。前後の比べ（直す前と直した後）を見せられるものがあれば教えてください。（載せる前に、お店の許可を取る必要があるかも確認させてください）
4. 「チラシは全然効かない」「広告はもう古い」と言う人に、どう答えますか。
5. 公式LINE（@486zunqz）に登録してくれた人へ、何をお渡しできそうですか。（例：記入シートの最新版、原稿の無料ひとことチェックを月○件まで、など）
6. 記事を読んだ人から「自分では無理なので作ってほしい」と言われたら、何を案内しますか。（チラシ制作、ホームページ、AI活用の教え方など。値段の案内のしかたも）
7. この記事で「これだけは言いたくない」「約束できない」ことはありますか。
