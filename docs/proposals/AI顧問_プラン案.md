# AI顧問 プラン案（鹿児島の不動産会社さま向け・社内用）

作成：営業担当 ／ 2026-11-20 ／ **2026-11-20 オーナー決定：3プランの金額はこの案のまま、診断は有料33,000円（契約で差し引き）、広告セットの特典はなし、訪問は鹿児島県内（交通費は別途かかる場合あり）**
前提：社長はITに強くない。最近パソコンを購入し、どこかで「Claude Code」などを習っているが役に立っていないと感じている。オーナーの「AIで業務を見直す」話に「世界観が違う」と感心し、「AIの顧問契約をしようかな」と発言。地域情報誌への広告掲載も検討中。

**読み取り**
- 都市部・全国向けの「AI顧問」は **月5万〜30万円** が中心。月1〜3万円台は「質問回数に上限がある」「研修だけ」など、内容がかなり絞られたものだけ。
- 鹿児島の中小企業にとって月5万円超は「高い」と感じられやすい（**推測**：地域の広告単価やオーナーの肌感覚から）。そのため、入り口は2万円台、本命は5万円台、とするのが現実的と判断。
- 「作業もしてくれる（動画・文章・広告運用）」は相場の顧問サービスにはあまりない。**タートルアドの強みは「教える＋代わりに作る」を両方できること**。

## 2. 顧問プラン案（3段階）

オーナーが一人で回せるよう、**月の作業時間の目安**を必ずつけた。訪問エリアは鹿児島県内（場所により交通費を別途いただく場合あり。2026-11-20 オーナー決定）。

|---|---|---|---|
| 月額（税込・案） | **22,000円** | **55,000円** | **110,000円** |
| 面談 | オンライン月1回（60分） | 訪問月1回（90分）＋オンライン月1回（30分） | 訪問月2回（各90分）＋オンライン月1回（30分） |

**共通のきまり（案）**
- 初回の「業務の見直し診断」（下の3.）を受けてから、どのプランにするか決めていただく。
- ホームページ制作（ライト55,000円〜＋月額5,500円）・地域情報誌の広告は**顧問とは別契約**。広告とセットにしたときの特典はつけない（2026-11-20 オーナー決定）。
- AIの有料プラン代（ChatGPT・Claudeなど、1人あたり月1,500〜3,000円程度）は御社負担。
- お客さまの個人情報（名前・電話番号・住所など）はAIに入れないルールを最初に一緒に決める。
- AIが書いた物件の文章は、**不動産の広告ルール（「最高」「格安」などの使えない言葉、二重価格など）に合っているか、最後は人が確認**する（宅建業者として責任を持つのは御社、という点を明記）。
- 3か月ごとに「やったこと・減った作業時間」を一枚にまとめて報告する。

**金額の考え方（オーナー向けメモ）**
- ライト：相場の最安クラス（1.5万円税抜で質問5問）より少し上。オンラインだけなので移動時間ゼロ。「まずお試し」の入り口。
- スタンダード：相場の顧問（5万円〜）と同じくらいの金額で、さらに動画2本と広告運用が入る。時間単価は約5,500〜7,000円。動画・広告を別々に頼むより割安に見えるので、**一番選ばれやすい**と予想（**推測**）。
- しっかり：作業量が多く、オーナー一人だと**同時に受けられるのは1〜2社まで**。最初の1社には無理にすすめない。

## 3. 初回「業務の見直し診断」

### 決定：**有料 33,000円（税込）。顧問を契約したら初月の料金から全額差し引く**（2026-11-20 オーナー決定）

理由
1. オーナーは時間が限られている。無料にすると「話を聞くだけ」の相談が増え、時間が取られる。
2. 社長は既に「顧問をしようかな」と前向き。今回の相手には有料でも十分受け入れられる見込み（**推測**）。
3. 「契約すれば実質0円」なので、社長にとって損がなく、契約を決める後押しになる。
4. 診断の結果（業務の一覧と「AIで減らせる時間」）は、契約しなくても社長の手元に残るので、お金を払う価値がはっきりしている。

（参考：地域情報誌の付き合いを大切にしたい場合は「無料30分の雑談 → 有料診断」の2段階も可。その場合も診断そのものは有料がおすすめ）

### 進め方（合計 約3週間・オーナーの作業 約5時間）

| 順番 | 内容 | 時間 |
|---|---|---|
| 1. 事前アンケート | 下の質問10個をLINEで送って答えてもらう（紙でも可） | 社長15分 |
| 2. 訪問ヒアリング | 社長（できれば事務の方も）に、1日の仕事の流れを聞く。実際のパソコンの画面・使っている紙やExcelを見せてもらう | 90分 |
| 3. 整理 | 仕事を「AIで減らせる／人がやるべき／そのままでいい」に分け、減らせる時間をざっくり計算 | オーナー2時間 |
| 4. 結果の説明 | A4一枚〜2枚で「すぐできること3つ」と「おすすめのプラン」を説明。1つはその場で一緒にやってみせる（例：物件の写真とメモから紹介文を作る） | 60分 |

### 社長に聞く質問リスト（10個）
1. 社員さんは何人ですか？ 売買・賃貸・管理のどれが多いですか？
2. 1日のうち、パソコンに向かっている時間はどれくらいですか？ 何をしていることが多いですか？
3. 一番「めんどうだな」「時間がかかるな」と感じている仕事を3つ教えてください。
4. 物件の紹介文は、誰が、どこに（自社サイト・ポータルサイト・チラシなど）、月に何件くらい書いていますか？
5. お客さまからの問い合わせは、どこから来ることが多いですか？（電話・ポータルサイト・ホームページ・紹介・情報誌など）
6. 問い合わせへの返事や、物件の案内のやりとりは、電話・メール・LINEのどれでしていますか？
7. InstagramやYouTubeなどのSNSはやっていますか？ やりたいけれどできていないことはありますか？
8. 今習っているパソコン・AIの講座では、何を習っていますか？ どこで「役に立たない」と感じましたか？
9. 今使っているパソコン・スマホ・ソフト（Excel、物件管理ソフトなど）を教えてください。
10. 1年後、「AIを入れてよかった」と思えるのは、どんな状態になっていたらですか？（例：残業が減る、問い合わせが増える、社員が育つ）

（オーナー向けメモ：8.で、今の講座が「Claude Code」のようなプログラマー向けの道具が中心なら、社長には合っていない可能性が高い。**推測**だが、社長に必要なのは「スマホやパソコンでAIに話しかけて文章を作る」レベルの使い方で、そこを丁寧に教えられるのがタートルアドの強み。今の講座を否定せず「目的に合わせて使い分けましょう」と伝えるのがよい）
