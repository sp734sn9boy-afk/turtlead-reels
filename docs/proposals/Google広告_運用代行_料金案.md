### まとめ（相場の読み方）
- **代理店**：「広告費の20%」が基本。ただ広告費が月1〜3万円だと20%は2,000〜6,000円にしかならないので、実際は「最低料金」を決めて断るか、高めの定額にしている会社が多いと思われる（**推測**。「最低手数料 月3万〜5万円」という具体的な数字は今回の検索では確認できなかった）。
- **フリーランス**：定額で **月3万〜5万円** くらいの出品が見つかった。初期設定だけなら1万円前後からある。
- **月1〜2万円の定額運用**は、今回の検索では見つからなかった。→ タートルアドが月2万円台を出せば、地方の小さい会社には「安い側」に入る（**推測**）。

### 確かさの注意
- 出典のほとんどが**運用代行を売る会社自身の記事**（stock-sun.com、atsoho.com など）で、公的な統計ではない。自社のサービスが安く・よく見えるように書かれている可能性がある。
- ランサーズ・ココナラの価格は**個人の出品価格**で、実際にその値段で売れているか（販売実績）は確認できていない。
- 今回の環境では atsoho.com・mynavi・imitsu.jp・ascii.jp などのページを直接開けず、**検索結果の要約で確認した内容**。数字の細かいところは、オーナーが決める前にパソコンで1〜2ページ見ておくと安心。

## 2. オーナーの作業時間の見積もり（広告費 月1〜3万円・1アカウント）

すべて**推測**。タートルアド自社の広告（1日330円、11/18設定・審査通過）を作った経験をもとにした目安。お客さま分は「聞き取り」「お客さまのアカウントでの作業」「報告」が増える。

### 最初だけ（初期設定）：約6時間
| 作業 | 時間 |
|---|---|
| 聞き取り（商圏・強み・問い合わせの取り方） | 1時間 |
| キーワード・除外キーワード・広告文づくり（AIで下書き→手直し） | 2時間 |
| アカウントの設定（お客さま名義・支払い設定・地域・予算・入札） | 1.5時間 |
| 問い合わせの計測（電話タップ・フォーム・LINE登録を数える設定） | 1時間 |
| 審査の確認・手直し、お客さまへの説明 | 0.5時間 |

### 毎月：約3.5時間
| 作業 | 時間 |
|---|---|
| 週1回のチェック（15分×4回）：おかしなクリックがないか、予算の消化 | 1時間 |
| 検索された言葉を見て、ムダな言葉を除外 | 0.5時間 |
| 広告文・キーワード・クリック単価の見直し | 0.5時間 |
| 月1回の報告（表示・クリック・費用・問い合わせを1枚に。ひな形とAIで短縮） | 1時間 |
| お客さまとのやりとり（LINE） | 0.5時間 |

→ 1社あたり月3.5時間なら、オーナー一人でも**3〜5社くらいまでは同時に持てる**（**推測**。顧問の仕事と合わせて考える）。

**共通のきまり（案）**
- 広告費は**お客さまのカードからGoogleへ直接支払い**（タートルアドは立て替えない）。

- 解約は1か月前までに連絡。最低契約期間（3か月）より前の解約は残りの月額をいただく。
- 成果（問い合わせ数）の約束はしない。毎月数字で報告する。
- 不動産の広告文は、不動産の広告ルールに合っているか**最後は御社が確認**（AI顧問案と同じ）。

## 5. おすすめと理由

**案A（初期設定 33,000円＋月額 22,000円・広告費 月3万円まで）**

1. **手間に見合う**：月約3.5時間で時間単価 約6,300円。顧問スタンダードと同じくらいで、オーナーの時間を安売りしない。
2. **相場より頼みやすい**：フリーランスの定額（月3〜5万円）より安く、代理店の「最低料金」や初期20万円〜と比べれば明らかに安い。地方の小さい会社でも出しやすい金額（**推測**）。
3. **分かりやすい**：小さい広告費だと「20%」型は毎回最低料金になるだけなので、最初から定額のほうが説明が簡単。「広告費を増やせと言われそう」という不安もない。
4. **顧問へつなげやすい**：ライト＋広告＝44,000円 → スタンダード55,000円が一番お得に見える並びになる。

**注意（正直なところ）**
- タートルアドの運用経験は**自社アカウント1つ・設定したばかり（11/18）**で、まだ「お客さまの問い合わせが何件増えた」という実績はない。最初の1〜2社は、**初期設定費を半額（16,500円）にする代わりに、結果を事例として紹介させてもらう**、という形も考えられる（**推測で提案**。決めるのはオーナー）。
- 広告費1万円のお客さまには「広告費より手数料のほうが高い」と感じられやすい。そのときは「月1万円でも、問い合わせ1件で元が取れる不動産は向いている」「まず3か月だけ」という説明でカバーする。
