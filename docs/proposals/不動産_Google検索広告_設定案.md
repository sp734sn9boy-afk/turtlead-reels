# 家を探している人に届く「Google検索広告」設定案

〇〇不動産さま向け ／ ご提案：タートルアド（合同会社turtle ad）

---

## どんな広告？
**「鹿児島市 中古住宅」などとGoogleで調べた人にだけ、御社の広告が出ます。**
調べているその瞬間に出るので、「いま家を探している人」に直接届きます。
費用は**クリックされたときだけ**です。見られただけではかかりません。

## 設定内容（案）

| 項目 | 設定 |
|---|---|
| 広告の種類 | Google検索広告（検索結果の上に出る広告） |
| 地域 | 鹿児島市（または鹿児島県内の御社の商圏）。「その地域にいる人」に限定 |
| 予算 | 1日330円〜（月およそ1万円〜）。上限を超えて請求されることはありません |
| クリック単価の上限 | 200円前後から開始 |
| 広告が出る時間 | 毎日 |
| クリックした人の行き先 | 物件ページ、またはLINEで物件情報を受け取る登録ページ |

## 広告を出すキーワード（例）
**売買**
- 鹿児島市 中古住宅 ／ 鹿児島市 中古一戸建て
- 鹿児島市 土地 ／ 〇〇町 売地
- 鹿児島 平屋 ／ 鹿児島市 新築一戸建て
- 鹿児島市 不動産 売却 ／ 家 売りたい 鹿児島

**賃貸**
- 鹿児島市 賃貸 ／ 鹿児島市 賃貸 2LDK
- 〇〇駅 賃貸 ／ 鹿児島 ペット可 賃貸

※広告を出さない言葉（例：「求人」「無料 査定 アプリ」など）も設定して、ムダなクリックを防ぎます。

## 広告の文章（例）
> **鹿児島市の中古住宅・土地なら〇〇不動産**
> 地元で〇〇年。未公開物件もご紹介。LINEで新着物件をお届けします。

## 毎月の報告
表示された回数、クリックされた回数、かかった費用、問い合わせの件数を、毎月わかりやすくお伝えします。

## なぜ不動産に向いている？
1件の取引の金額が大きいので、月1万円の広告でも、**問い合わせが1件取れれば元が取れる計算**になりやすいです。
