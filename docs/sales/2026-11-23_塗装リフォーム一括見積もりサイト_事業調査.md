# 塗装・リフォーム「一括見積もり（一括紹介）サイト」事業調査

作成：営業担当（2026-11-23）／依頼：リーダー／対象：オーナー案

> 調べ方の注意：今回の環境では、ウェブページを直接開く機能（WebFetch）が多くのサイトで使えず（ネットワーク制限）、**検索結果の要約と出典URLだけを根拠にしています**。各社の公式料金ページを直接開いて確かめたわけではありません。業者向け料金はどの大手も「非公開・要問い合わせ」が多く、数字はブログ・比較記事・掲示板の書き込みが中心です。根拠の強さを「強い／中／弱い」で付けています。【推測】は私の見立てです。

## 1. 結論

**「条件つきでやる」。ただし、オーナー案のままではなく、形を変えて小さく試す。**

- やってよい理由：業者が払う金額（紹介1件1万円＋成約5万円）は、相場と比べて**安め〜ふつう**で、業者にとって受け入れやすい。地元情報誌の宣伝枠を使えば、いちばんお金がかかる「お客さん集め」を安くできる見込みがある。仕組み（フォーム→複数社に一斉通知）は自社で作れる。
- そのまま始めない理由：
  1. **「5社に届けて10万円」は現実的ではない。** 大手でも紹介は最大3〜4社まで（外壁塗装の窓口は最大4社）。5社だと「電話が多すぎる」というお客さんの不満の元になる。**最大3社・お客さんが選ぶ形**にすべき。現実的な1件あたりの売上は**約3.8万〜4.5万円**（10万円ではない）。
  2. **ネット広告だけで集めると赤字になりやすい。** 外壁塗装の問い合わせ1件をネット広告で取る費用は1〜3万円が目安（競合が多い地域は7万円の例も）。全国の大手（ヌリカエ・外壁塗装の窓口・ミツモア）も鹿児島で広告を出している【推測】。黒字になるかは「誌面・チラシでどれだけ安く依頼を集められるか」でほぼ決まる。
  3. **成約料は、業者が正直に報告しないと取れない。** 1人の会社で見張るのは大変。最初は成約料を軽くするか、紹介料中心にする案も検討したい。
- **いちばん大きなリスク**：紹介した業者が手抜き工事やトラブルを起こしたとき、「マイタウンガイドが紹介した業者」として**本業の情報誌の信用が傷つく**こと。次に、依頼が月に数件しか来ず、業者が離れていく（業者もお客さんも集まらない「鶏と卵」）こと。
- 最初の3か月で「依頼15件以上・ネット1件あたりの獲得費2万円以下・業者が続けたいと言う」を満たさなければ、やめる（撤退ラインを最初に決めておく）。

## 2. 理由（調べたこと）

### 2-1. 競合と、業者が払っている料金

| サイト | 業者の料金（わかった範囲） | 規模など | 根拠の強さ |
|---|---|---|---|
| ヌリカエ | 公式は非公開。「紹介時」と「成約時」に払う成果報酬型、初期費用・月額なしとの解説。紹介料1件18,000円という加盟業者の知人の話あり（成約しなくても払う） | 加盟3,500社超、成約44,500件以上との記載／別記事では2,000社以上 | 弱い〜中 |
| 外壁塗装の窓口 | 月額の固定費は無料。初期登録費・手数料は「要問い合わせ」。紹介時2万円とする記事あり | 最大4社まで紹介。問い合わせ月5,000件超、800社以上登録との記載 | 中（社数は公式寄りの記述）／料金は弱い |
| ペイプロ | 月額25,000円＋紹介料4,500円/件、成約手数料0円のプラン紹介 | 150社だけと契約（少数精鋭型） | 弱い |
| 外壁塗装駆け込み寺 | 成約手数料10%とする古い比較記事（約6年前） | — | 弱い |
| ホームプロ | 公式数字は見つからず。2014年の掲示板で「業者が6%の仲介手数料」との書き込み | NTT東日本・リクルート系、利用者数最大手とされる | 弱い |
| くらしのマーケット | 手数料約20%とする記事（外壁塗装専門ではない） | — | 弱い |
| 業界全体の目安 | **紹介料：1件5,000〜20,000円程度。成約手数料：工事代金の10〜20%が一般的**（100万円の工事なら10〜20万円）。入会金30万円＋紹介1件15,000円＋成約10%という例も | — | 中（複数記事で一致） |

**オーナー案（紹介1件1万円＋成約5万円）との比較**
- 紹介料1万円：相場（5,000〜20,000円）の**真ん中くらい**。ヌリカエの18,000円（うわさ）より安い。
- 成約料5万円：外壁塗装は1件70万〜150万円ほど（30坪で約61〜70万円、50坪で116万円〜の記事あり）なので、相場の10〜20%なら**7〜30万円**。5万円は**かなり安い**。業者に勧めやすい売りになる。
- 初期費用・月額なし：大手と同じ水準。業者が入りやすい。

**鹿児島での状況**
- ヌリカエの鹿児島県の加盟業者数は見つからず（根拠なし）。ミツモアは鹿児島県の市町村ごとに業者ページあり（南九州市・曽於市など）。比較ビズの鹿児島市ページは更新が2024年8月で古い。→ **全国の大手は鹿児島にも来ているが、鹿児島専門の強いサイトは見当たらない**（根拠：中。検索で見つからなかった、という意味）。
- 鹿児島県内の外壁塗装の助成金がある市町村は32か所との記事あり（年度で変わる）。→ 誌面の「助成金の情報」と組み合わせると呼び込みに使える【推測】。
- 鹿児島県の塗装工事業の許可業者数は、県の名簿PDFで数えられる（今回は数えられていない）。

### 2-2. お客さんを集める費用

| 方法 | 目安 | 根拠の強さ |
|---|---|---|
| Google広告 1クリック | 外壁塗装で300〜800円が相場。「外壁塗装 東京」874円、「外壁塗装 徳島」501円（2026年6月時点の例）。都心は1,000円超も | 中（広告会社のコラム複数） |
| 見積もり依頼1件あたり（広告） | 1〜3万円が目安（関東5社の実績）。競合が多い地域で7万円の例 | 中 |
| クリック→問い合わせ | 10人クリックして1人いるかどうか | 弱い〜中 |
| チラシ・折込 | 反響率0.01%（1万枚に1件）は不動産の目安で外壁塗装の統計ではない。折込1枚約3円・ポスティング約5円→1件あたり3〜5万円の計算 | 弱い |

- 「外壁塗装 鹿児島」の1クリックの値段は、直接のデータは見つからず。徳島の例から**400〜600円くらい**と見ています【推測】。問い合わせ率を5〜10%とすると、ネットでの1件あたり**5,000円〜1.2万円**ですが、大手と競り合うとこれより上がります【推測】。安全側で**2万円**で試算しました。
- **情報誌での集客**：自社媒体の空き枠・自社広告枠を使えば、追加でかかるお金は小さい（印刷はどのみち出る）。「地元の情報誌が審査した業者だけ」「電話は選んだ会社からだけ」は、大手にない安心感として読者に響く可能性がある【推測】。ただし反響数は誰にもわからないので、**最初の号で実際に数えるしかない**。

### 2-3. 業者側の本音

- 不満（中〜弱い）：
  - 成約しないお客さん（相場だけ知りたい人）にも紹介料がかかる（ヌリカエ18,000円の話）。
  - 手数料が高く、見積もりに上乗せせざるを得ない／値下げ競争になる、との指摘が複数。
  - 「お客さんと直接やりとりしたい」と一括見積もりに一切登録しない地元業者もいる（愛知の業者ブログ）。
  - 掲載先が多いと業者は費用対効果を厳しく見る。
- それでも使う理由：自社でネット広告をやると月20〜50万円、SEOは成果まで半年〜1年かかる。紹介サイトは**すぐ・成果分だけ**払えばよい。
- 「地元の情報誌の会社のサイトなら登録したい」要素【推測】：
  - 成約料が大手の半分以下（5万円固定）。
  - 顔の見える会社・すでに取引がある（掲載企業）。
  - 紹介は最大3社・地元業者だけで、全国の安売り業者と比べられにくい。
  - 誌面で会社紹介も載る（今の広告とセットにできる）。
- 注意：すでにマイタウンガイドに広告を出している塗装会社がいる場合、**広告費が減る（食い合う）**か、**「紹介されなかった会社」から不満が出る**おそれがある【推測】。

### 2-4. お客さん側の不満と、避ける工夫

- 不満（中）：迷惑電話・ショートメールが来る／業者の質にばらつき／紹介後に連絡がつかなくなった、など。登録すると「見込み客」として業者が先を争って電話してくる。
- 工夫（大手の例と私の案）：
  - 紹介は**最大3社**（窓口は最大4社）。
  - **お客さんが業者を選ぶ**（会社名・写真・実績を見て選んでから送る）。同意も取りやすくなる【推測】。
  - 連絡方法を「電話OK／メール・LINEのみ」から選べるようにする。
  - 断りの連絡を代わりに入れる「お断り代行」【推測：大手での実施は今回確認できず】。
  - 業者には「しつこい営業は禁止・違反は登録取り消し」と約束してもらう（ヌリカエも強引な勧誘を禁止とされる）。

### 2-5. 法律・決まり（専門家の確認が前提）

| 項目 | わかったこと | 根拠の強さ |
|---|---|---|
| 個人情報（複数の業者に渡す） | 本人の同意なしに第三者へ渡すのは原則ダメ。**事前に同意を取り、記録を残す**。第三者に渡したときは、渡した相手などの記録を作って保存する義務がある（個人情報保護委員会ガイドライン）。同意なしで渡す「オプトアウト」は委員会への届け出が必要 → 使わない | 強い（公的ガイドライン） |
| 紹介料をもらう許可 | 自分で工事を請け負わず紹介だけなら、建設業許可が必要になる可能性は低いと一般に考えられている。**工事代金を自社で受け取らない・契約はお客さんと業者が直接**にすることが大事。うちが実質的に請け負うと許可や「丸投げ禁止（一括下請負）」の問題が出る | 中（直接の公的見解は見つからず） |
| 不動産 | 売買・賃貸の仲介で報酬を取るのは宅建業法の免許が必要（一般知識）→ **不動産は対象外にする** | 中（一般知識） |
| 景品表示法 | 「No.1」「最安」などは根拠（比較対象・調査方法）がないと違反。2024年10月から悪質なものに罰則。消費者庁が「No.1表示」の実態調査を公表 → **No.1・最安は使わない**。「お客さまのご利用は無料（費用は登録業者が負担）」と書く | 強い〜中 |
| ステルスマーケティング | 紹介料をもらっているのに中立のように見せるのは、2023年10月からの景品表示法の告示で問題になる（一般知識）→「当サイトは登録業者から紹介料をいただいて運営しています」と明記 | 中（一般知識・今回の検索で直接は確認できず） |
| 特定商取引法の表示 | マッチングサイトが対象になるかは仕組みしだい（直接の答えは見つからず）。会社名・所在地・連絡先などはどのみち載せる | 弱い |
| 業者側の訪問販売 | 訪問見積もりで自宅で契約すると、業者側は訪問販売の決まり（8日以内のクーリングオフ）が関わる。うちの紹介業者がこれを守るよう規約に入れる | 中 |
| 成約の報告 | 大手がどう見張っているかは、今回は確認できず。わかったのは「業者は成約時に払う」形だということだけ | 根拠なし |

**成約報告の仕組みの案【推測・専門家確認】**
1. 業者との契約書に「成約したら○日以内に報告」「報告しなかったことがわかったら成約料の2倍を払う」「登録取り消し」を入れる。
2. お客さんに1か月後・3か月後に「どこかと契約しましたか？」とLINE・メールで確認（n8nで自動化できる）。答えてくれた人に、QUOカード1,000円などのお礼（※景品表示法の景品の上限内か要確認）。
3. 「施工事例として誌面・サイトに無料で載せる」と業者に持ちかけ、成約を自分から言いたくなる形にする。
4. それでも難しければ、**成約料をやめて紹介料だけ（1社1.5万円など）**にする選択肢も持っておく。

### 2-6. 収支のざっくり試算

**前提（すべて【推測】を含む）**
- 紹介は最大3社。紹介料1万円/社。成約料5万円。
- 「有効な依頼」の割合（いたずら・重複・対象外を除く。無効分は業者に請求しない）：85%（ふつう）
- 依頼のうち、どこかと契約まで行く割合（成約率）：30%（ふつう）【推測：公開データなし。相見積もりで3社から1社選ぶので、依頼の2〜4割が契約と見た】
- 1件あたりのオーナー作業：1.5時間（内容確認の電話、業者への送信、成約確認）。時給3,000円で換算。
- 毎月の固定費：ツール・050電話など5,000円＋業者対応4時間（1.2万円）＋契約書の確認費を12か月で割る（約0.8万円）＝**約2.5万円/月**
- ネットからの依頼1件の広告費：2万円。誌面からの依頼は追加費用0円（自社枠）とする。

## 3. 始め方の案（小さく試す）

1. **地域と工事を絞る**：鹿児島市・姶良市・日置市あたり、**外壁塗装・屋根塗装だけ**。リフォーム全般・不動産は後回し（不動産は対象外）。
2. **業者は5〜6社そろえば始める**（1件に3社届けるには、休み・対応不可を考えて倍ぐらい必要）【推測】。条件：建設業許可または施工実績、賠償保険の加入、しつこい営業をしない約束。
3. **紹介は最大3社・お客さんが選ぶ・連絡方法も選べる**。
4. **料金**：初期費用・月額0円、紹介料1万円/社（無効な依頼は請求しない）、成約料5万円（工事代金に関係なく固定）。最初の3か月は「お試し期間として成約料なし」も選択肢。
5. **集客**：マイタウンガイドの自社枠で「地元審査済みの塗装店を最大3社ご紹介・助成金の相談も」の特集＋ネット広告は月5万円まで。
6. **測る数字**：依頼数（誌面／ネット別）、1件あたり広告費、3社そろった割合、業者ごとの成約数、お客さんの満足度。
7. **3か月で判断**：依頼15件以上・ネットの1件あたり2万円以下・業者の過半数が継続希望 → 続ける。満たさなければやめる、または「業者向けの集客支援（ホームページ＋AI動画＋誌面広告）」に切り替える。

**業者への営業の一言（たたき台・オーナーが言う想定。送信・連絡はしていません）**
> 「マイタウンガイドで、鹿児島市周辺の外壁塗装のご相談を地元の塗装店さんだけにおつなぎする窓口を始めます。初期費用・月額は0円で、ご紹介1件1万円、ご成約時のみ5万円の固定です。大手サイトのように工事代金の1〜2割をいただくことはありません。お客さんがご紹介先を選ぶ形で、1件につき最大3社までです。まずは5社限定でご参加いただける塗装店さんを探しています。」

## 4. リスクまとめ

| リスク | 大きさ | 対策 |
|---|---|---|
| 紹介業者のトラブルで情報誌の信用が落ちる | **大** | 審査基準、保険加入、苦情が続いたら登録取り消し、「工事契約はお客さまと業者の直接契約」と明記 |
| 依頼が集まらない（鶏と卵） | **大** | 誌面で先に試す。撤退ラインを決める |
| ネット広告が大手と競って高くなる | 中〜大 | 月5万円の上限。地域名＋細かいキーワードに絞る |
| 成約の報告漏れ | 中 | 契約書の違約条項、お客さんへの自動アンケート、紹介料中心の料金への切り替え |
| 既存の広告主（塗装会社）との関係 | 中 | 先に既存の掲載企業から声をかける（オーナー対応）。広告の割引とセットにするか検討 |
| 個人情報の扱い | 中 | 同意画面（渡す業者名を表示）、提供記録の保存、プライバシーポリシーの専門家確認 |
| オーナーの時間が取られる | 中 | 受付〜送信〜成約確認はn8nで自動化。電話確認は1件10分以内に |
