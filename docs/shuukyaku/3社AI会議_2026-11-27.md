# 3社AI会議（2026-11-27）

質問：当社の集客計画の一番の弱点／今月〜来月の打ち手3つ／1万円メタ広告テストの是非／地域情報誌の強みの使い方
（n8n「他社AIに意見を聞く」実行番号3223。お客様名・個人情報は送っていない）

## 各AIの意見（要約）
| | Gemini | GPT |
|---|---|---|
| 一番の弱点 | 月3万円の伴走は安すぎ・手間がかかりすぎ。14社で代表の時間が尽きる | 実績と信頼が足りない。無料診断や広告だけでは有料契約になりにくい |
| 打ち手 | ①掲載企業へ無料診断 ②1社で成功例を作る ③紹介制度 | ①掲載企業上位10社に個別無料診断＋1か月お試し ②情報誌でセミナー・診断クーポン ③広告は既接触者向けに限定 |
| 1万円テスト | 今のフォロワー数ではお試しにも足りない。チラシ印刷などに回すほうが契約に近い | 新規向けには弱い。リターゲティング（一度接触した人向け）に限定 |

## リーダー（Claude）の結論
- 3社とも一致：**一番の弱点は「自社の実績の数字がないこと」**。一番の近道は**既存の掲載企業で1社、数字の出る事例を作る**こと（指示書の進め方①と同じ）。
- Geminiの「手間がかかりすぎ」への反論：設定・集計・レポートはAIが行う前提なので、代表の時間は増やさない。ただし品質を保つため、最初は**伴走は5社まで**に絞る。
- 1万円テストは**続ける**。目的は契約ではなく「1フォロー単価とDM数の実測」で、これがお客さまに広告を勧める根拠になる。GPTの案を取り入れ、プロフィール訪問者・動画視聴者への**再表示（リターゲティング）を一部に入れる**。
- セミナーやチラシの配布は代表が客先で使う武器の候補。やるかどうかは代表が決める。

## 弱いところ
- 他社AIの意見も根拠は推測。数字の検証は、毎日の「集客データ（毎日）」と広告テストの実測で行う。
