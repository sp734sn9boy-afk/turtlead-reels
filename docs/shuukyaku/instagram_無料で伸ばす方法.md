# Instagram お金をかけずにフォロワー・いいねを増やす方法

作成：2026-11-27／出品・発信担当（調査）
対象：@turtle_ad、@my_town_job
※有料の方法（広告など）は別の担当がまとめています。

---

## 結論：増やせます。ただし「数日」ではなく「月単位」です

- 「増やせない」と思う必要はありません。Instagramは2024年から「フォロワーが少ない人のオリジナル投稿も、合いそうな人に少しずつ見せる」仕組みに変えたと公式に説明しています。小さな会社にも、フォロワー以外に届く道はあります。
- ただし、増えるのは「見た人が最後まで見る・人に送る・保存する」投稿だけです。投稿を並べるだけでは増えません。
- 順番は「届く人数（リーチ）を増やす → その中からフォローされる」です。フォロワー数を直接増やす近道（購入・自動ツール）は規約違反で、アカウントが止まる危険があります。
- 今の手動フォロー（約3分の1がフォロー返し）は、地元に知ってもらう方法として良い結果です。ただし、ペースを守らないと操作制限がかかります。

## 3. 今やっている「鹿児島の会社を手動でフォロー」の評価

### 評価
- 【事実】2アカウントで約110人・約160人のフォロー返し、返す率は約3分の1（オーナーからの報告）。
- 【推測】一般に、知らない相手からのフォローに返す率は1〜2割程度と言われることが多く、3分の1は良い結果です。「鹿児島の会社」に絞っているので、将来お客さんになり得る相手がフォロワーに入っている点でも価値があります。
- 【推測】ただし、フォロー返しで増えた人は投稿を熱心に見るとは限りません。フォロワー数は増えても、いいねや送信は増えにくいことがあります。この方法は「地元の会社に名前を知ってもらう」役目、投稿の工夫は「フォロワー以外に届ける」役目、と分けて考えるのがよいです。

### 操作制限を避ける注意点
- 【事実】Instagramはフォローなどの操作に回数制限をかけており、具体的な上限は公表していません。超えると「〇〇できる頻度を制限しています」という表示が出て、一時的に操作できなくなります。
  https://www.online-tech-tips.com/how-to-fix-we-limit-how-often-you-can-do-certain-things-on-instagram-error/ （二次情報）
- 【未検証】非公式の目安は「1日約150回」「1時間10回前後」、フォロー総数の上限7,500。新しいアカウントはもっと厳しいとの説もあり。
  https://metricool.com/instagram-limits/ ／ https://www.pathsocial.com/ja/resources/instagram-follow-limit-per-day/
- 【推測】安全のための守り方（下の「明日からやること5」に手順を書きました）
  - 1アカウントあたり1日20〜30人まで、10人ごとに時間をあける
  - フォロー解除をまとめてしない（「フォロー → すぐ解除」を繰り返すのは制限を受けやすい）
  - 制限の表示が出たら、そのアカウントは48時間フォローを止める
  - 同じ文章のコメントやDMを何件も送らない

## 4. やってはいけないこと

### 【事実（出典URL）】
- **フォロワー・いいねの購入、増やすアプリの利用**：偽のいいね・フォロー・コメントを作る外部アプリはInstagramの規約（コミュニティガイドライン・利用規約）違反。Instagramは、こうしたアプリで得たいいね等を削除し、アカウントを停止・削除することがあると説明している。
  https://help.instagram.com/263751177667145 （検索結果の抜粋で確認）
  https://about.instagram.com/blog/announcements/reducing-inauthentic-activity-on-instagram/ （検索結果の抜粋で確認）
- **ログイン情報を外部ツールに渡す自動フォロー・自動いいねツール**：上と同じく違反。アカウント乗っ取りの危険もある。
- **他人の投稿の転載中心の運用**：おすすめ対象外になる（1の「オリジナル優遇」参照）。
- **ハッシュタグの大量付け**：5個までしか付けられない。

### 【推測】
- 「いいね回り」（大量のアカウントに機械的にいいねして回る）は、手作業でも短時間に大量にやると、自動ツールと同じ扱いで制限される可能性があります。いいねは本当に見た投稿だけ、コメントは中身のある一言にしてください。
- 「フォロー・いいね・コメントを交換し合うグループ」も、Instagramが嫌う不自然な反応にあたる可能性が高く、避けるべきです。

## 5. 明日から2アカウントでやること（5つ）

### その1：おすすめに乗れる状態か確認する（各アカウント5分・1回だけ）
1. Instagramアプリで自分のプロフィール → 右上の三本線 → 「アカウントステータス」を開く
2. 「おすすめできるか」が緑（問題なし）か確認。問題があれば、その投稿を直すか消す
3. アカウントが「公開」「プロアカウント（ビジネス）」になっているか確認
4. プロフィールの1行目に「鹿児島の〇〇」「何をしてくれるか」を入れる（例：@my_town_job「鹿児島の求人・働く人を紹介」）

### その2：リールを週3本、「送りたくなる中身」で作る
1. 1本目の最初の3秒に、結論を大きな文字＋ナレーションで出す（例：「鹿児島で今月いちばん応募が多かった求人は？」）
2. 中身は「人に送りたくなる情報」にする。@turtle_ad＝AIで仕事が楽になる小技・ホームページの失敗例、@my_town_job＝鹿児島の会社の中の様子・求人まとめ
3. 自分で撮った・作ったオリジナルのみ。他アプリの透かしなし。3分以内（目安30〜60秒）
4. ハッシュタグは3〜5個（例：#鹿児島 #鹿児島求人 #鹿児島ランチ など内容に合うもの）
5. 今あるn8nの自動投稿の仕組みとナレーション入りリールの作り方をそのまま使い、本数を週3本にそろえる
6. 週1回、インサイトで「平均視聴時間」「送信数÷リーチ」「3秒以降も見た割合」をメモし、数字が良かった型を増やす

### その3：週1本は「試用リール」でフォロワー以外に試す
1. リール投稿の最後の画面で「試用（トライアル）」をオンにする（表示が出ない場合は、フォロワー数などの条件を満たしていない可能性あり）
2. 「72時間後に成績が良ければ自動で共有」をオンにする
3. 24時間後に結果を確認。良かったテーマは通常リールでも続ける
- 【未検証】n8nの自動投稿から試用リールで出せるかは未確認。仕組み担当に確認が必要です。

### その4：コラボ投稿で、お互いのフォロワーに届ける
1. @turtle_ad と @my_town_job で月2本、コラボ投稿をする（フォロワーが多い方が作成・招待する）
2. @my_town_job で掲載企業を紹介するリールは、その企業のアカウントを共同投稿者に招待する（企業側が承認すると、その会社のフォロワーにも表示される）
3. 招待は投稿前に設定する（あとから追加はできない）
- 【注意】企業を招待するのは「お客様への連絡」にあたるため、最初の1件は内容をオーナーが確認してください。

### その5：手動フォローは続ける。ただし安全なペースで
1. 1アカウントあたり1日20〜30人まで。10人フォローしたら1時間ほどあける
2. フォローする前に相手の最新投稿を見て、良いと思えば1つだけいいね・中身のある一言コメント
3. フォロー解除はまとめてしない（するなら1日10人程度まで）
4. 「制限しています」と出たら、そのアカウントは48時間フォローもいいねも止める
5. 週1回、フォロワー数と「フォロー返しの数」を記録する
