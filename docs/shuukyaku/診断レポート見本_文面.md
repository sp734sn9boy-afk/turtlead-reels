## 1. ひとことで言うと

- **見られてはいるのに、予約の手前で取りこぼしています。** 投稿を増やすより先に、「見た人が予約しやすい形」に直すのが近道です。
- 最初の一手は、**お金のかからないGoogleマップの整備と、ホームページの予約の入口の見直し**です。
- 広告はそのあとに少額から。整骨院は広告に書けることが法律で限られているので、**書ける内容で選ばれる作り方**をします。

## 2. いまの数字と、取りこぼしている場所

### 新しい患者さんが予約するまでの流れ（1か月・見本の数字）

| 段階 | 数 | 次へ進んだ割合 |
|---|---|---|
| ① 表示（Googleマップ・検索で院が表示された回数） | 3,500回 | ― |
| ② 行動（ホームページを開く・電話・道順を調べる） | 合計 約300回 | 表示の 約8.6% |
| 　うちホームページの訪問 | 約250回 | |
| ③ 問い合わせ（電話・LINE・予約フォーム） | 13件 | 行動の 約4.3% |
| 　うちホームページからの問い合わせ | 3件 | 訪問の 約1.2% |
| ④ 新規予約・来院 | 10件 | 問い合わせの 約77% |

参考：Instagram（見本の数字）　投稿の表示 約2,000回／プロフィールを見た人 約40人／ホームページへのリンクを押した人 約6人

### どこで取りこぼしているか

1. **ホームページに来た人が、ほとんど問い合わせていない（約1.2%）。** 目安の約2%を下回っています。来てくれた人に「予約の仕方」「初めての流れ」が伝わっていない可能性が高いです。
2. **Googleマップで表示されても、行動につながる割合が低い。** 写真と口コミが少なく、他院と比べたときに選ばれにくい状態です。
3. **Instagramは、いまのフォロワーの中で回っていて、新しい人にあまり届いていません。** いいねやフォロワーを増やすこと自体が目的ではなく、「この院なら安心」と感じてもらう材料として使い方を変えます。
4. 問い合わせ→予約（約77%）は良い数字です。電話やLINEの対応は今のままで大丈夫そうです。

> 実際の診断では、Googleマップの管理画面・ホームページのアクセス解析・予約台帳から、院の本当の数字を出します。

## 3. 見つかった課題（大事な順）

### 課題1　Googleマップの情報が少ない（写真が少ない・説明が短い）
- **なぜ問題か**：「地域名＋整骨院」で探す人の多くが、まずGoogleマップで比べます。写真が少ないと、院内の雰囲気や入口が分からず、不安で別の院を選ばれます。
- **当社がやること**：外観・入口・駐車場・受付・施術スペース・スタッフの写真をそろえて掲載。営業時間・休みの日・予約方法・駐車場の情報を正しく整えます。Googleマップの利用は無料です。

### 課題2　ホームページで予約の入口が分かりにくい
- **なぜ問題か**：スマホで開いたとき、電話番号やLINE予約のボタンがすぐに見つからないと、そのまま閉じられてしまいます。
- **当社がやること**：画面の上と下に「電話する」「LINEで予約」のボタンを常に表示。「初めての方へ（来院から施術までの流れ・所要時間・持ち物・駐車場）」のページを作り、来院の不安を減らします。

### 課題3　口コミが8件で、増える仕組みがない
- **なぜ問題か**：★4.1は良い評価ですが、件数が少ないと比べたときに目立ちません。
- **当社がやること**：お会計のときに**全員へ同じ文面とQRコード**でお願いする仕組みを作ります（受付に置くカードやLINEのお礼メッセージ）。いただいた口コミへの返信文の下書きもお手伝いします。
  ※割引やプレゼントと引き換えにお願いすること、満足していそうな人だけに頼むことはしません（7章）。

### 課題4　新しい患者さんが「何を見て来たか」を数えていない
- **なぜ問題か**：きっかけが分からないと、どこにお金と時間をかけるべきか判断できません。
- **当社がやること**：問診票に「当院を知ったきっかけ」の欄を追加。ホームページとGoogleマップの数字を毎月まとめ、予約台帳と合わせて見られるようにします。

### 課題5　広告をまだ使っていない（使うなら作り方に工夫が必要）
- **なぜ問題か**：今困っている人が「鹿児島市 整骨院」などで検索したとき、上のほうに出られていません。ただし整骨院の広告は、症状名や「保険が使えます」などが書けないため、普通の作り方では効きにくい面があります。
- **当社がやること**：書ける内容（院名・場所・時間・予約方法・駐車場など）で選ばれる広告文を作り、詳しい説明はホームページで読んでもらう形にします（5章・7章）。

### 課題6　Instagramの投稿が新しい人に届いていない
- **なぜ問題か**：週3回の投稿は続いていますが、いいね平均5・フォロワー180で、新しい患者さんにつながりにくい状態です。
- **当社がやること**：投稿の目的を「院の雰囲気・スタッフの人柄・初めての流れが伝わること」に変え、プロフィールから予約までの道をつなぎます。あわせて、投稿の文章に広告では使えない言葉（7章）が入っていないかを点検します。

## 4. 広告費の使い方の提案（月3万円の場合）

広告費はお店さまのご負担で、Googleなどにお店さまのカードで直接お支払いいただきます（当社が立て替えたり、上乗せしたりはしません）。広告の設定・見直しは当社が行います。

| 使い道 | 月の金額の目安 | 理由 |
|---|---|---|
| Google検索広告 | 1日700円 → 月の上限 21,280円 | 「今、近くの整骨院を探している人」に届くため。いちばん予約に近い人です |
| メタ広告（Instagram・Facebook） | 1日250円 → 月 約7,500円 | 院の近くに住む人に、院内の様子やスタッフを知ってもらうため |
| Googleマップ | 0円 | 整備は無料。まずここを整えてから広告を出します |
| 調整分 | 約1,200円 | 月によって使う金額が前後するための余裕 |

**Google広告の金額の仕組み**
- Google広告は「1日の予算」を決めます。日によっては1日の予算の2倍まで使うことがありますが、**1か月の請求は「1日の予算×30.4」が上限**です（30.4＝365日÷12か月）。上限を超えた分は請求されません。
- 例：1日700円なら、月の請求は最大 700×30.4＝21,280円です。
- 予算の変更は、計算がずれないよう月初にまとめて行います。

**最初にお伝えしておきたいこと**
- 月3万円の場合、広告の良し悪しを判断できるだけの数字（クリック約300回が目安）がそろうまでに、**2〜3か月かかる見込み**です。最初の期間は「データを集める期間」とお考えください。
- 媒体はこの配分に決めつけません。院の場所・患者さんの年代によっては、チラシや地域の情報誌のほうが合う場合もあります。数字を見ながら毎月組み替えます。
- メタ広告の1日の最低金額は広告を作る画面で確認します（見本の金額は目安です）。

## 6. 広告で気をつけること（大切なルール）

### 整骨院の広告には、書けることが決まっています
- 整骨院・接骨院（柔道整復師法）や、はり・きゅう・マッサージ（あはき法）の広告は、**法律で決められた項目しか出せません**。出せるのは、施術者の氏名、院の名前・住所・電話番号、業務の種類、施術日・施術時間などです。違反には罰則があります。
- 自治体の資料で、広告に使えない例として挙がっているもの：
  - 症状名：「腰痛」「肩こり」など
  - 効果を思わせるメニュー名：「骨盤矯正」「姿勢改善」「小顔矯正」など
  - 保険の表示：「各種保険取扱い」「各種保険適用」（交通事故・労災などを含むと受け取られるため）
  - 施術料金、経歴、「治す」「治療」、交通事故治療の表示
- 2025年2月に厚生労働省が「あはき・柔整広告ガイドライン」を出し、書いてよい範囲がはっきりしました。

### どこが「広告」に当たるか
- **チラシ・Google広告・メタ広告・バナー広告は「広告」です。** 上のルールが当てはまります。
- **Instagramなどの投稿も、条件によっては広告として規制の対象になりえます。** 当社が関わる投稿は、上のルールに沿って作ります。
- **ホームページは、ガイドラインでは規制の対象外とされています。** ただし、内容を自主的に適正にすることが求められており、うそや大げさな表現は使えません。そのため、詳しい施術の説明はホームページに置き、広告は「院名・場所・時間・予約方法」で興味を持ってもらう形にします。
- 検索広告で「腰痛」などの言葉で検索した人に広告を出すこと（広告文には書かない）の扱いは、役所の見解が確認できていません。迷うものは使わないか、保健所に確認してから使います。

### 口コミのお願いのしかた
- **割引・プレゼント・ポイントと引き換えに口コミを頼むことは、Googleのルールで禁止されています。** 違反すると、新しい口コミが受け付けられなくなる、今ある口コミが見えなくなる、といった制限がかかることがあります。
- 星の数を指定したり、満足していそうな人だけに頼んだりすることも禁止です。
- 医療機関では、割引と引き換えに口コミを頼んだクリニックや、口コミにお金を払った歯科医院に、国（消費者庁）から措置命令が出た例があります。
- 当社では「特典なし・星の指定なし・全員に同じお願い」の方法だけで進めます。

> 法律の解釈は当社の整理で、法律相談ではありません。判断に迷う表現は、保健所に確認してから使います。
