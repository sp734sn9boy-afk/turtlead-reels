## 1. 機能の3段階と、上級者向けで増えるもの

### 確認済み（公式ページの抜粋に書いてある）
出典：https://support.google.com/youtube/answer/9890437 、https://support.google.com/youtube/answer/9891124

| 段階 | 条件 | 主な機能 |
|---|---|---|
| 標準 | チャンネルを作るだけ（有効な違反警告がないこと） | 動画・ショートのアップロード、再生リスト作成など |
| 中級者向け | **電話番号の確認** | **15分を超える動画**、**カスタムサムネイル**、ポッドキャスト作成、（版によっては）**パソコンからのライブ配信** |
| 上級者向け | 電話確認 ＋「十分なチャンネル履歴」**または**「身分証明書／動画による確認」 | **収益化の申請**、**コメントの固定**、**チャプター**、**長尺動画の概要欄と投稿（コミュニティ投稿）に押せるリンク**、**1日のアップロード上限などの引き上げ（higher daily limits）**、RSSでのアップロード、ライブ配信の埋め込み、**Content ID の申し立てへの異議（appeal）**、A/Bテスト（サムネイルのテストと比較）、複数言語の機能 など |

- 身分証明書・動画による確認は、すべてのクリエイターが使えるわけではない。確認できるのは**メインのチャンネル所有者だけ**。
- 上級者向け機能でも、使いすぎて上限に達した場合は **24時間待ってから**また使える。
- 一覧の中身は言語・地域の版で少し違う。**自分のチャンネルの正確な一覧は YouTube Studio の「機能の利用資格」で確認**、と公式も案内している。

## 2. 機能を失う条件と、動画認証の保存期間

### 確認済み
出典：https://support.google.com/youtube/answer/9890437 、https://support.google.com/youtube/answer/2802032 、https://support.google.com/youtube/answer/9891124

- **コミュニティガイドラインを守らない**、または**良いチャンネル履歴を保たない**と、上級者向け機能を失うことがある。例として「コミュニティガイドラインの違反警告」「著作権侵害の警告」が挙がっている。
- 違反警告の1回目：**1週間、アップロード・ライブ配信・カスタムサムネイルなどができなくなる**。警告は **90日間**残る。上級者向け機能を失うこともある。
- 著作権侵害の警告は「チャンネル履歴」の判定に影響する。
- 機能が無効になった動画がたくさんあるチャンネルは、ライブ配信も止められることがある。

### 動画認証（顔の動画）・身分証のデータの保存期間（確認済み）
出典：https://support.google.com/youtube/answer/9891124 、https://support.google.com/accounts/answer/12270735
- 動画認証の目的：実在の人か、年齢がGoogleのサービスを使える年齢か、過去に停止されたアカウントでないか、の確認。
- **十分なチャンネル履歴ができてから数か月後**、または**上級者向け機能を1年使わなかった場合は1年後**に、ふつうは削除される。
- 不正防止のために、動画と顔認識データを **YouTubeを最後に使った日から最長3年**保持することがある。
- Googleアカウントから**2年以内に自動で削除**、という記載もある（版・ページで書き方が違う）。
- 自分で削除もできるが、**チャンネル履歴が十分になる前に削除すると、上級者向け機能を失う**。

→ 実務上のポイント：**データは消さずにそのまま**にしておく。毎日投稿を続けていれば「チャンネル履歴」がたまり、認証に頼らずに上級者向けを維持できる方向になる（ここは推測）。

## 3. YouTube Data API（自動投稿）との関係

### 確認済み（developers.google.com の抜粋）
- **APIの割り当て（クォータ）**：プロジェクトごとの標準は「**videos.insert が1日100回**」「search.list が1日100回」「ほかの全部の合計で1日10,000ユニット」。**videos.insert は専用の枠（Video Uploads）で1回＝1ユニット**扱い。リセットは**太平洋時間の午前0時**（日本時間で冬は17時、夏時間中は16時）。出典：https://developers.google.com/youtube/v3/determine_quota_cost 、https://developers.google.com/youtube/v3/docs/videos/insert
  - ※以前は「videos.insert＝1,600ユニット（10,000ユニットで1日6本程度）」だった。第三者の記事では「2026年6月1日に変わった」とされている（公式の改訂日はページ本体で未確認）。**thumbnails.set は 50ユニット**（以前からの表の数字）。
  - 10,000ユニットを超える割り当てがほしい場合は「API コンプライアンス監査」が必要。
- **thumbnails.set**：API からサムネイルを設定できる。必要な権限（スコープ）は youtube / youtube.force-ssl / youtube.upload / youtubepartner のどれか。**ショートにカスタムサムネイルを付けるときは、動画の処理が終わってから（processingDetails.processingStatus が succeeded になってから）呼ぶ**こと。処理中に呼ぶと、ショートには反映されないことがある。403 のエラーは「この動画には設定できない」「このユーザーにはカスタムサムネイルを設定する権限がない」の2種類。出典：https://developers.google.com/youtube/v3/docs/thumbnails/set
- **チャンネルのアップロード上限とAPIの割り当ては別物**：チャンネルの「24時間の上限」は**パソコン・スマホ・APIの合計**にかかる（YouTube側の上限）。APIのクォータは**Google Cloud のプロジェクト側**の上限。どちらかに当たると止まる。出典：https://support.google.com/youtube/answer/10383400 、https://developers.google.com/youtube/v3/determine_quota_cost
- 2020年の改訂メモ：**確認（監査）を受けていないAPIクライアントで上げた動画は「非公開」にロックされる**ことがある。出典：https://developers.google.com/youtube/v3/revision_history （※いま公開で上がっているなら、うちは影響を受けていないと考えられる＝推測）

### 以前の HTTP 429 の原因候補（推測）
公式ページで「429が何を意味するか」は見つけられませんでした。以下は推測です。
1. **短時間に何度も同じリクエストを送った**（テストで連続実行、n8n の自動リトライが短い間隔で重なった等）→ 一時的な回数制限。いちばんありそう。
2. **アップロード上限（uploadLimitExceeded）や割り当て切れ（quotaExceeded）**に当たった。公式の書き方では、これらは本来 400／403 で返ることが多い（uploadLimitExceeded は 400 という第三者情報あり）。n8n 側の表示やノードの仕様で 429 に見えた可能性。
3. テスト期間に**1日に何本も上げた**ため、新しいチャンネル（当時は上級者向けではなかった）の24時間上限に当たった。
- 見分け方：エラー本文の JSON の **`reason`** を見る（`rateLimitExceeded`／`quotaExceeded`／`uploadLimitExceeded` など）。次に起きたら、仕組み担当に n8n の実行ログの `reason` を見てもらうのが早い。
- 今は毎日1本なので、**APIの割り当て（100回/日）にもチャンネル上限にも余裕がある**と考えられる（推測）。

## 4. 売上につなげる案（提案まで。公開・設定変更はしていません）

前提（確認済み）：ショートの概要欄・コメントのURLは押せない。押せる導線は「ショートの関連動画リンク」「長尺の概要欄リンク」「チャンネルのプロフィールのリンク」「コメントの固定」。

### 案A【最優先】ショート → 長尺「サービス紹介動画」への関連動画リンク
- 何をする：1〜3分の長尺（横でも縦でもよい）「タートルアドのAI動画・ホームページ制作のご案内」を1本作り、**概要欄の1行目に LINE（@486zunqz）とリンク集 https://www.turtle-ad.com/links/ を押せるリンクで入れる**。毎日のショートの「関連動画」にこの1本を設定する。
- なぜ：ショートでは外部リンクが押せないが、関連動画は押せる（上級者向け機能で解禁）。ショート→長尺→LINE の2タップ導線ができる。
- 最初の一歩：仕組み担当が HyperFrames（make_daily.py の型）で「サービス紹介」長尺の台本と動画を作る。デザイン担当がサムネイル。
- オーナーの作業：台本の確認（10分）、YouTube Studio で関連動画を設定する or 「n8nで自動設定してよい」と承認（5分）。
  - 補足（推測）：関連動画を API で設定できるかは公式で確認できていない。できなければ手作業か、Studio で一括。

### 案B 長尺の概要欄テンプレート＋固定コメント
- 何をする：長尺動画の概要欄の先頭に「AI動画・ホームページのご相談はLINEで → （LINEのURL）」「料金と事例 → https://www.turtle-ad.com/links/」を入れる定型文。自分のコメントを**固定**して同じ案内を出す（固定は上級者向け）。
- 最初の一歩：出品・発信担当が概要欄テンプレートと固定コメント文を作る（料金は CLAUDE.md の決まり：ホームページはライト55,000円〜＋月額5,500円が必須、の表記に合わせる）。
- オーナーの作業：文面の承認（5分）。

### 案C ショートにもカスタムサムネイル（9:16）を付けて、チャンネルページの見た目をそろえる
- 何をする：毎日のショートに、タートルとタイトル文字の入った 9:16 のサムネイルを自動で作って付ける。チャンネルページを見た人に「ちゃんとした会社」と伝わり、問い合わせの信用につながる（推測）。
- 技術：make_daily.py でサムネイル画像も出力 → n8n で videos.insert のあと、**処理完了（processingStatus=succeeded）を待ってから thumbnails.set**（50ユニット）。
- 最初の一歩：仕組み担当が「処理完了待ち → thumbnails.set」を n8n にテスト追加（限定公開の動画で試す）。
- オーナーの作業：見本サムネイル3案から選ぶ（5分）、本番に入れる承認（1分）。

### 案D お客さま向けの「事例紹介」長尺（売り物そのものの見本）
- 何をする：「ロゴからキャラクターAI動画を作るまで」「ホームページを作るとGoogleマップとどうつながるか」などを5〜10分で解説。HyperFrames の型で量産できる。チャプター（上級者向け）を付けて見やすくし、概要欄に押せるリンク。
- なぜ：ショートは認知、長尺は「頼むか決める」材料。営業時に URL を送るだけで説明が済む（営業担当の資料にもなる）。
- 最初の一歩：営業担当＋出品・発信担当で、問い合わせでよく聞かれそうな質問を5つ選び、1本目の台本を作る。
- オーナーの作業：テーマの選択と台本の確認（15分）。実在のお客さまの事例を出す場合は、お客さまの許可を取る（オーナー）。

### 案E 「投稿（コミュニティ投稿）」で押せるリンク付きのお知らせ
- 何をする：週1回、チャンネルの「投稿」に「今月のご相談受付」「無料でできるGoogleマップ点検」などを、押せるリンク付きで出す（投稿内リンクは上級者向けで押せる、と公式一覧にある）。
- 最初の一歩：出品・発信担当が4週分の投稿文を下書き。
- オーナーの作業：まとめて承認（10分）。

### やらない方がいいこと（確認済みの規約から）
- 同じ「LINEはこちら」コメントをたくさんの動画に機械的に書き込むのは、YouTube のスパムポリシー（大量・くり返しのコメントで誘導）に当たるおそれ。出典：https://support.google.com/youtube/answer/2801973
- テスト目的で1日に何本も上げない（24時間上限と違反判定の両方のリスク）。

## 5. オーナーにお願いしたいこと（まとめ）
1. YouTube Studio →「設定」→「チャンネル」→「機能の利用資格」を開き、上級者向けが「有効」になっているか見る（2分）。スクリーンショットをLINEで送ってもらえると、一覧を正確に清書できる。
2. 動画認証のデータは**削除しない**（消すと、チャンネル履歴が足りないうちは上級者向けを失う）。
3. 案A〜Eのうち、進めてよいものを選ぶ（おすすめは A → B → C の順）（5分）。
