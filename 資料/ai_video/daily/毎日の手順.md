# AI動画編集部 YouTubeショート 毎日の手順（HyperFrames版の型）

新しいクラウドのセッションが、ここだけ読めばゼロから1本作れるように書いています。
**作るところまで**です。YouTubeへの公開・投稿、n8n本番の変更はしません（公開はオーナーの承認が必要）。

- 型の元：`資料/ai_video/hyperframes版/`（オーナーが「これはいいね」と選んだ型）
- 作る道具：`資料/ai_video/daily/make_daily.py`（台本.json 1つ → 声 → 場面 → チェック → MP4 → 確認コマ）
- 見本：`資料/ai_video/daily/サンプル/`（台本.json と完成MP4・確認コマ）
- 台本のひな形：`資料/ai_video/daily/台本ひな形/土曜_実例.json`、`日曜_今週のまとめ.json`

---

## 0. 所要時間のめやす

| 作業 | 時間 |
|---|---|
| 最初だけ：Docker起動＋VOICEVOXのイメージ取得（約1.9GB）＋起動 | 3〜6分（イメージがもうあれば30秒） |
| 最初だけ：HyperFrames CLI の取得（npx） | 30秒〜1分 |
| 1本あたり（35秒の動画）：声 15秒・場面 1秒・チェック 10秒・書き出し 約110秒・確認 5秒 | **約2分半** |
| 日曜（60〜90秒）の書き出し | 4〜5分 |

書き出しは「動画の長さ × 約3.2倍」かかります（このクラウドはGPUなし・ソフトウェア描画のため）。

## 1. 準備（セッションの最初に1回）

すべてリポジトリの一番上（`/home/user/turtlead-reels`）で実行します。

### 1-1. テレメトリ（利用状況の送信）を止める ※必ず
```bash
export HYPERFRAMES_NO_TELEMETRY=1 DO_NOT_TRACK=1 DISABLE_TELEMETRY=1
node ~/.claude/skills/hyperframes/scripts/plugin-cli.mjs telemetry disable
```
- `make_daily.py` も中で同じ3つを必ずセットしてから HyperFrames を呼びます。
- HyperFrames スキルの「usage beacon（`hyperframes events`）」と「`feedback`」は**実行しない**。

### 1-2. Docker を起動
```bash
nohup dockerd > /tmp/dockerd.log 2>&1 &
for i in $(seq 1 30); do docker info >/dev/null 2>&1 && break; sleep 1; done
docker info | grep "Server Version"     # 表示されればOK
```

### 1-3. VOICEVOX エンジンを起動（春日部つむぎ）
```bash
docker run -d --rm --name vv -p 50021:50021 voicevox/voicevox_engine:cpu-ubuntu20.04-latest
for i in $(seq 1 60); do curl -s --noproxy '*' -m 2 localhost:50021/version && break; sleep 2; done
```
- `"latest"` などのバージョンが返ればOK。最初はイメージ取得で数分かかります（Docker Hub から取れることは確認済み）。
- 確認：`curl -s --noproxy '*' localhost:50021/speakers | grep -o 春日部つむぎ` → 「春日部つむぎ」（ノーマル＝id 8）。

### 1-4. HyperFrames（動画にする道具）
- 使い方は `~/.claude/skills/hyperframes/SKILL.md` と `~/.claude/skills/hyperframes-cli/SKILL.md` を先に読む。
- 呼び方：`node ~/.claude/skills/hyperframes/scripts/plugin-cli.mjs <コマンド>`（作業中のプロジェクトのフォルダで）。今回確認したCLIは **0.9.72**。
- スキルが無い環境では、`make_daily.py` が自動で `npx --yes hyperframes@0.9.72` を使います（別の場所なら `HF_CLI=/path/to/plugin-cli.mjs` を指定）。
- Chrome が無いと言われたら：`node ~/.claude/skills/hyperframes/scripts/plugin-cli.mjs browser ensure`
- 必要なもの：Node.js 22以上（`/opt/node22/bin/node`）、ffmpeg / ffprobe、Python3 の numpy と Pillow（無ければ `pip install numpy pillow`）。

### 1-5. フォントの場所
- `資料/ai_video/fonts/NotoSansJP-Bold.ttf`（本文・字幕）
- `資料/ai_video/fonts/RoundedMplus1c-ExtraBold.ttf`（番号・見出しの丸文字）
- どちらも SIL Open Font License（商用OK）。`make_daily.py` が毎回 `project/assets/fonts/` にコピーします。動かさないこと。

## 2. 台本ファイルを書く

置き場所：`資料/ai_video/daily/<日付>/台本.json`（例：`資料/ai_video/daily/2026-11-21/台本.json`）

**曜日の型**（`type` を書かなければ日付から自動で決まります）

| 曜日 | type | 番組名（画面） | 長さの目安 | items の数 |
|---|---|---|---|---|
| 月〜金 | `weekday` | 今日のAIニュース | 30〜45秒 | 1 |
| 土 | `saturday` | AIで仕事が楽になった実例 | 30〜45秒 | 1 |
| 日 | `sunday` | 今週のまとめ | 30〜90秒 | 2〜4（番号①②③が付く） |

※ **11/21（明日）は土曜日**なので、初回は `saturday`（実例）の型になります。ニュースで出したい場合は `"type": "weekday"` と書けば切り替わります。

### 2-1. 形（見本：`サンプル/台本.json`）
```json
{
  "date": "2026-11-21",
  "type": "weekday",
  "speed": 1.22,
  "hook": {
    "headline": "Claudeに 新しいAIが登場",
    "say": [{"sub": "Claudeに、新しいAIが出ました。", "read": "クロードに、新しいエーアイが出ました。"}]
  },
  "items": [
    {
      "headline": "新しいAI「Claude Fable 5.2」",
      "date_label": "発表 11月9日",
      "source_label": "出典：Anthropic公式",
      "source_url": "https://www.anthropic.com/claude-fable-and-mythos-5-2",
      "beats": [
        {"card": {"type": "title", "text": "新しいAI/**「Claude Fable 5.2」**"},
         "say": [{"sub": "Anthropicが、新しいAI/「Claude Fable 5.2」を出しました。"}]},
        {"card": {"type": "tip", "items": ["ふだんの仕事 → 今のAI", "むずかしい作業 → **新しいAI**"]},
         "say": [{"sub": "ふだんの仕事は、今のAIで十分。"}]}
      ]
    }
  ],
  "highlight": ["Claude Fable 5.2", "十分"],
  "description_extra": "概要欄の1行目に入る説明文"
}
```

### 2-2. 項目の意味
| 項目 | 中身 |
|---|---|
| `date` | 公開する日（YYYY-MM-DD）。画面の「11/21号」「11/21(土)」になる |
| `type` | `weekday` / `saturday` / `sunday`（省略で日付から自動） |
| `speed` | 声の速さ。**1.2〜1.25**（標準 1.22） |
| `hook.headline` | 0秒目から出る見出し（つかみ）。短く、20字以内 |
| `hook.say` | つかみのセリフ。**2秒以内**（1文・15字前後）にする |
| `items[].headline` | 見出しカードの文（上の帯） |
| `items[].date_label` / `source_label` | 見出しカードの下の小さい文字（例「発表 11月9日」「出典：Anthropic公式」） |
| `items[].source_url` | 出典URL。**必須**（概要欄に入る。無いと注意が出る） |
| `items[].source_urls_extra` | 追加の出典URL（あれば。配列） |
| `items[].beats` | カード1枚ずつのまとまり。1ネタで **3〜5枚**（ポイント2〜3つ＋「中小企業ならこう使える」） |
| `beats[].say` | そのカードの間に話すセリフ（字幕1枚＝1要素） |
| `say[].sub` | 字幕。`/` で改行（**2行まで**・1行18字くらいまで）。`**ことば**` で黄色 |
| `say[].read` | 読み方（省略可）。英語名や数字の読みがあやしいときだけ書く。ひらがな・カタカナで |
| `highlight` | 字幕で黄色にする言葉 |
| `readings` | 読み方の置きかえを追加（例 `{"Sora": "ソラ"}`）。よく使うもの（Claude, ChatGPT, Gemini, AI, 十分, 日本 など）は登録済み |
| `cta_say` | 宣伝カードのセリフを変えたいときだけ（標準：「このキャラクターのようなAI動画を、御社のロゴから作ります。」） |
| `title` | 概要欄のタイトル案（省略で「見出し｜番組名 日付」） |
| `description_extra` | 概要欄の1行目 |
| `program` | 番組名を変えたいときだけ |

### 2-3. カードの種類（`card.type`）
| type | 使いどころ | 書く項目 |
|---|---|---|
| `title` | 見出し・大きな一言 | `text`（`/`で改行・`**`で黄色）、`chip`（小さい札・任意） |
| `number` | 数字を数え上げて見せる | `top`（上の小さい文）、`prefix`、`value`（数字）、`suffix`、`after`、`note` |
| `points` | ポイント2〜3つ（チェック印つき・セリフに合わせて1つずつ出る） | `items`（最大3）、`title`（任意） |
| `tip` | 「中小企業ならこう使える」の札＋2〜3行 | `items`（`→` は水色になる）、`label`（札の文字を変えるとき） |
| `stamp` | ハンコ（ベータ・無料・最大2.5倍など） | `stamp`、`text` |
| `icon` | アイコン＋文 | `icon`（`pin` / `phone` / `clock`）、`text`、`note` |

**毎回同じで自動で入るもの**（台本に書かなくてよい）
- 上部の帯「AIが情報収集から動画まで作っています」
- 冒頭と最後の「この動画は、タートルアドのAIチームが情報収集から台本・音声・映像まで作っています」
- クレジット「VOICEVOX:春日部つむぎ」（画面下と最後のカード）
- 最後の宣伝カード（約4.7秒）：「このキャラクターのようなAI動画を、御社のロゴから作ります」「キャラクターAI動画のご相談はこちら」「LINE公式 @486zunqz」「turtle-ad.com」。タートルが小さくなって手をふり、最後にお辞儀。
- 概要欄のLINEリンク（https://line.me/R/ti/p/@486zunqz）とホームページ（https://turtle-ad.com/）

### 2-4. 書くときの決まり
- 事実は出典に書いてあることだけ。「中小企業なら」は提案として言う。わからないことは言わない（`2026-11-20_第1回/ネタ一覧.md` の書き方と同じ）。
- 1本の長さは「セリフの合計文字数 ÷ 約7文字/秒 ＋ 宣伝カード5秒」がめやす。平日35秒なら本文セリフは**170〜200字**。
- ひな形の `【…】` が残っていると実行が止まります（書き忘れ防止）。

## 3. 作る（1つのコマンド）

```bash
cd /home/user/turtlead-reels
python3 資料/ai_video/daily/make_daily.py 資料/ai_video/daily/2026-11-21/台本.json
```
オプション：
- `--no-render` … 声・場面・チェックまで（書き出しなし。台本の長さ確認に便利。約25秒）
- `--draft` … 下書き画質で書き出し（確認用）
- `--force` … HyperFrames のチェックでエラーが出ても書き出す

中で起きること：
1. **声づくり**：セリフ1つずつ VOICEVOX（春日部つむぎ・ノーマル）でWAVを作る。`voice/` にキャッシュするので、直して再実行しても変えたセリフだけ作り直す。
2. **場面組み立て**：`project/`（HyperFramesのプロジェクト）に index.html と compositions/（intro・item1〜・cta・captions・turtle・chrome・wipes）を書く。口パク・まばたきは声の時刻から自動。効果音・BGMは自作の音（著作権の心配なし）。
3. **チェック**：`hyperframes check --json`（エラー0が条件）、字幕のはみ出し、長さが型の目安に入っているか、宣伝カードの秒数、出典URLの有無。
4. **書き出し**：`hyperframes render --quality delivery` → `turtle_ai_<日付>.mp4`（1080×1920・30fps・音声AAC）
5. **確認**：ffprobe で長さと音声を照合、場面ごとのコマを `確認コマ/` にPNGで保存し、`確認コマ/contact_sheet.jpg`（一覧）を作る。

## 4. できあがるもの（台本.json と同じフォルダ）
| ファイル | 中身 |
|---|---|
| `turtle_ai_<日付>.mp4` | 完成動画 |
| `確認コマ/contact_sheet.jpg` | 場面ごとのコマ一覧（**必ず目で見る**：文字のはみ出し・重なり・誤字） |
| `概要欄.txt` | YouTubeの概要欄に貼る文（タイトル案・LINE・ホームページ・出典・AI制作の表示・クレジット） |
| `秒数表.md` | 何秒に何を言うか＋VOICEVOXの実際の読み（読み間違いの確認用） |
| `チェック結果.txt` / `check.json` / `render.log` | チェックと書き出しの記録 |
| `project/` / `voice/` | HyperFramesの中身・声のキャッシュ（直すときに使う） |

完成後、リーダーに「MP4・contact_sheet・概要欄.txt」を渡す。公開はオーナーの承認後。

## 5. 毎日の流れ（自動化するとき）
1. 情報収集・分析係が当日のネタを1つ選ぶ（出典URLつき）。
2. 台本.json を書く（日付・型・セリフ・カード・出典）。
3. `--no-render` で長さを確認 → 長すぎ・短すぎならセリフを調整。
4. 書き出し → `確認コマ/contact_sheet.jpg` と `秒数表.md` の読みを確認。
5. リーダーへ報告（公開はしない）。

## 6. よくあるつまずき
| 症状 | 原因と直し方 |
|---|---|
| `VOICEVOX につながりません` | エンジンが起動していない。1-2・1-3 をやり直す。`docker ps` で `vv` があるか確認。起動直後は10〜20秒待つ |
| `Cannot connect to the Docker daemon` | dockerd が止まっている。1-2 を実行 |
| curl で localhost に届かない | プロキシ経由になっている。`--noproxy '*'` を付ける（make_daily.py は自動でプロキシを通さない） |
| 読み方がおかしい（例：十分→じゅっぷん、日本→にっぽん、英語名） | `秒数表.md` の「読み」を見て、そのセリフに `"read"` を書く。よく出る言葉は `readings` に追加 |
| `字幕がはみ出しそう` | `/` の位置を変えて2行に分ける。1行18字まで |
| `長さ ○秒は、この型の目安の外` | セリフを足す・削る（平日は30〜45秒） |
| `台本にひな形の【…】が残っています` | ひな形の【】を書きかえる |
| HyperFrames が `Chrome` / `browser` で失敗 | `node ~/.claude/skills/hyperframes/scripts/plugin-cli.mjs browser ensure` |
| 書き出しが遅い | 正常（GPUなしのソフト描画で長さの約3.2倍）。日曜90秒なら5分弱。ツールの時間切れが心配なら `run_in_background` で実行 |
| check の「注意」（YouTube Shortsの右端の安全範囲・小さい文字など） | 元の型（HyperFrames版）と同じ配置から出るもの。エラーではない。気になるときは check.json を見る |
| `npx` で HyperFrames が取れない | npm の取得がネットワークで止められている。スキル（~/.claude/skills/hyperframes）があるセッションで実行する |
| カードの文字が大きすぎ・小さすぎ | 文字の大きさは枠に合わせて自動で縮む。長すぎる文は短くするのが一番 |
