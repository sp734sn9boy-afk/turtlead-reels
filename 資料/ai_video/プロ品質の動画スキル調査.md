# 「プロっぽい動画にして」と頼むためのスキル・プラグイン調査

- 調査日：2026-11-20（情報収集・分析係）
- 質問：Claude Code（や Claude Fable 5.2）で、プロが作る動画みたいにするためのスラッシュコマンド・スキル・決まったコードはあるか
- 調べ方：Web検索（2025〜2026年の情報を優先）、npm／PyPI の登録情報、この作業環境での動作確認（インストールはしていない）
- 注意：remotion.dev、sdtimes.com などはこの環境から直接開けなかった（ネットワーク設定で許可されていない）。そのため一部は検索結果の要約にもとづく。重要な数字は、オーナーかリーダーが公式ページで最終確認してください。

---

## 結論（先に）

- **「これを打てばプロ品質」という魔法の1コマンドは、Anthropic公式にはない。**（事実：公式の動画機能「Claude Motion」はあるが、Claude Code のコマンドではなく、Team／Enterprise プランだけのベータ）
- その代わり、**動画づくりの「型」を Claude に教えるスキル**が、動画ツールの会社から公式に出ている。代表は次の2つ。
  1. **Remotion 公式スキル**（remotion-dev/skills。中心は remotion-best-practices）
  2. **HyperFrames**（HeyGen 社が出している、HTML から MP4 を作る仕組み＋公式スキル／Claude Code プラグイン）
- タートルアドの今の作り方（ffmpeg＋PIL、ドット絵の口パク、VOICEVOX）に足すなら、**第1候補は HyperFrames**（Apache 2.0 で商用も無料、npm で入る、GitHub にも届く）。**第2候補は Remotion**（機能と事例は一番多いが、社員4人以上の会社は有料ライセンス。タートルアドは今は1人なので無料の範囲の可能性が高い→要確認）。

## 2. 実際に作っている人の手順とコツ（事例）

事実（各記事に書かれていること）：
- 流れはどれもほぼ同じ：**台本 → 場面ごとの設計（何秒に何を出すか）→ Claude がコードを書く → 書き出し → 見て直す**。
  - https://beginnersinai.org/youtube-shorts-factory-claude-remotion/ （Remotion でショート量産）
  - https://dev.to/ayyazzafar/i-built-a-youtube-shorts-generator-with-ai-heres-how-36dn （データの差し替えで次の動画ができる）
  - https://www.mindstudio.ai/blog/generate-ai-videos-claude-code-hyperframes-elevenlabs-workflow （HyperFrames＋ElevenLabs）
  - https://apidog.com/jp/blog/claude-code-remotion/ （日本語）
- プロンプトのコツとして書かれていること：
  1. **大きさと速さを数字で指定**（例：1080×1920、30fps）
  2. **秒数・登場のタイミング・置く場所を具体的に**書くと精度が上がる
  3. **台本の長さに制限をつける**（例：つかみは10語以内、要点3つ各20語以内）
  4. **字幕は必ず入れる**（ショートは字幕つきのほうが見られる、という主張）
  5. **1つ型を作り、中身（台本・色・画像）だけ差し替えて量産**する
- 限界：Remotion は「モーショングラフィックス（文字・図形の動き）」が得意。実写っぽい映像は別の生成AIと組み合わせている（https://www.mejba.me/blog/claude-code-remotion-youtube-motion-graphics）。
- 注意：多くは個人ブログで、再生数などの成果の数字は示されていない。

## 3. タートルアドの今の作り方に足すなら

今の作り方：ffmpeg＋PIL（Python で絵を1枚ずつ作って動画に）、ドット絵キャラ「タートル」の口パク、VOICEVOX の声、縦型ショート。

### この作業環境で動くか（事実：2026-11-20 に確認）
- ある道具：Node 22、Python 3、ffmpeg、Google Chrome（/usr/bin/google-chrome）
- npm：`hyperframes`（0.9.72）、`remotion`（4.0.545）、`skills`（1.9.0、MIT、vercel-labs 製）は取得できる
- PyPI：`manim`（0.22.1）は取得できる
- GitHub：`remotion-dev/skills` と `heygen-com/hyperframes` の中身は読めた（`npx skills add` が使える見込み）
- 推測：Remotion は書き出し時に専用のブラウザを別の場所から取ってこようとすることがある。届かない場合は、手元の Chrome を指定すれば動く見込み（未検証）。

### 足したときに何が良くなるか（推測を含む）
| 候補 | 効くところ | 今の仕組みとのつなぎ方 | 手間 |
|---|---|---|---|
| **HyperFrames** | 文字のアニメ（はねる・すべる・強調）、字幕、場面転換、グラフ。Web のデザインがそのまま使える | タートルの口パク動画（今の ffmpeg 出力）と VOICEVOX の音声を素材として HTML に置き、上に字幕やテロップの動きを重ねて MP4 に | 小〜中。HTML なので、ホームページ制作の技術・素材と共通 |

## 4. おすすめ上位3つと使い方

### 1位：HyperFrames（HeyGen 公式、Apache 2.0）
- 理由：商用無料で人数の制限がない、npm で入る、Claude Code 用のプラグインが公式にある、HTML なので今のサイト制作の技術と共通。
- 入れ方（リーダーかオーナーが承認してから）：
  ```
  npx skills add heygen-com/hyperframes
  ```
  またはプラグインとして：
  ```
  claude plugin marketplace add heygen-com/hyperframes
  ```
- 打つ言葉の例：
  - 「/hyperframes:hyperframes で、資料/ai_video/2026-11-20_第1回/台本_ショート.md を 1080×1920・30fps・30秒の縦型ショートに。タートルの口パク動画（tmp/xxx.mp4）を画面下半分に置き、VOICEVOX の音声に合わせて大きめの字幕を1行ずつ出して。つかみは最初の2秒で大きな文字がはねて出る。最後の3秒は『ホームページ制作 55,000円〜／月額5,500円』とロゴ」
  - 「この動画の場面ごとの秒数表を先に出して。OKしたら書き出して」

### 2位：Remotion 公式スキル（remotion-best-practices）
- 理由：作例・解説が一番多く、字幕や縦型ショートの情報も多い。プロっぽさの「型」が豊富。
- 注意：タートルアドが4人以上の体制になったら会社ライセンスが必要。今は「3人以下」の無料の範囲の可能性が高い（**オーナーが規約を確認**）。
- 入れ方：
  ```
  npx skills add remotion-dev/skills --skill remotion-best-practices
  ```
- 打つ言葉の例：
  - 「Remotion のスキルを使って、この台本で縦型ショート（1080×1920、30fps）を作って。字幕はカラオケ風に今読んでいる言葉を黄色に。タートルの動画は素材として使って」
  - 「この型の台本・色・画像だけ差し替えて、来週分の3本を作れるようにして」

### 3位：ffmpeg スキル（digitalsamba の toolkit のうち必要なものだけ）
- 理由：今の仕組みを変えずに、仕上げ（Instagram・YouTube 用の書き出し、音量そろえ）だけ底上げできる。
- 入れ方の例（中身を読んでから）：`npx skills add digitalsamba/claude-code-video-toolkit --skill ffmpeg`
- 打つ言葉の例：「ffmpeg スキルで、この動画をインスタのリール向けに書き出して。音量はそろえて、ファイルは小さく」

### 参考：「プロっぽく」するための、どのスキルでも効く頼み方（推測を含むまとめ）
1. 大きさ・速さ・長さを数字で（1080×1920、30fps、30秒）
2. 先に「場面ごとの秒数表（絵コンテ）」を出させて、OKしてから作る
3. つかみ（最初の2秒）・字幕・最後の呼びかけを必ず入れる
4. 色・文字の太さ・ロゴを「決まりごと」として最初に渡す（毎回同じ見た目になる）
5. 1本目を型にして、中身の差し替えで量産する

## 5. 注意点

### ライセンス
- **Remotion は「オープンソース」ではなく「ソース公開」**。4人以上の会社は有料。お客さまの動画を量産して売るときも条件を確認（事実：規約に人数の基準あり。量産販売の扱いは未確認）。
- HyperFrames（Apache 2.0）、Manim・Motion Canvas・skills CLI（MIT）は商用で使える。
- 声：VOICEVOX はキャラごとに利用規約が違う（クレジット表記など）。今の声の規約は別途確認済みのものに従う。
- Canva・HeyGen・ElevenLabs は使った分だけ料金や利用枠を使う。

### 安全性（知らない人のスキル・プラグインを入れるリスク）
- 事実：セキュリティ会社 Snyk が 2026-02 に公開スキル 3,984 個を調べたところ、**約13.4%（534個）に重大な問題、76個に悪意のある中身**が見つかった（https://snyk.io/blog/toxicskills-malicious-ai-agent-skills-clawhub/）。
- スキルは Claude と同じ権限で動くので、悪いスキルはパスワードや鍵（n8n のログイン情報など）を読めてしまう。
- 守り方（推奨）：
  1. **提供元が会社の公式リポジトリのものだけ入れる**（remotion-dev、heygen-com、anthropics）。同じ名前の「コピー版」（davila7、sickn33 など）は使わない。
  2. 入れる前に SKILL.md と付いてくるスクリプトを読む（リーダーか仕組み担当がチェック）。
  3. まずはこのクラウド環境で試し、オーナーのパソコンには入れない。
  4. 入れることは「取り消しにくい変更」に近いので、**オーナーの承認後に**仕組み担当が行う。
